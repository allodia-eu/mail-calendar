# An IPv6 address works as a mail server

Platforms: all
Bump: patch

> A mail server given as an IPv6 address, bare (`::1`) or in brackets with a port (`[::1]:993`),
> is accepted in setup and on an account's page, where it used to read as no server at all. The
> core splits and joins every server's host and port, so each form shows the port it dials.

**English**

```
A mail server given as an IPv6 address, such as [::1]:993, is now accepted in setup and on an account's page.
```
