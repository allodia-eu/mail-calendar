# The Android composer leaves room for the message

Platforms: android
Bump: patch

> A drag that started on From, To or Subject scrolled nothing, the outlined fields took a third of
> the screen, and the formatting toolbar wrapped to three rows, so with the keyboard up the message
> had two lines. The header is now flat rows that scroll with the message, and the bar keeps to
> Attach and Send.

**English**

```
Writing on Android has more room: the address fields are plain rows that scroll with the message, the formatting toolbar is one row shown while you write, and Save as draft, Signature and Discard are in the ⋮ menu.
```
