# Choose what a Microsoft or Google account is used for before signing in on Linux

Platforms: linux
Bump: minor

> The Microsoft and Google cards offer mail, calendar, contacts and, for an organisation's
> account, colleagues, and the sign-in asks the provider for those alone. A use the provider did
> not allow is named on the account's page in Settings, where switching it on asks again.

**English**

```
On Linux, a Microsoft or Google sign-in asks only for what you choose to use the account for, and says what the provider did not allow.
```
