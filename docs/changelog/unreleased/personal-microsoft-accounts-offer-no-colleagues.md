# A personal Microsoft account no longer asks for colleagues on Linux

Platforms: linux
Bump: patch

> A personal Microsoft account has no organisation directory, and Microsoft never grants one, so
> Settings → Accounts showed "Colleagues: needs permission" that no sign-in could fix. Whether an
> account is personal is now asked of Microsoft and stored with it, and a personal account offers
> no colleagues.
