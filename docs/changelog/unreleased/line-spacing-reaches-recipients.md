# Lines reach recipients spaced as they were written

Platforms: all
Bump: patch

> Every line went out as a `<p>`, which other clients draw with paragraph spacing and Outlook with
> 14pt above and below, so a message typed line by line arrived spread out. A line now goes out as
> a line, and a paragraph states its own spacing.

**English**

```
Lines in a message now reach recipients, Outlook included, spaced as they were in the composer.
```
