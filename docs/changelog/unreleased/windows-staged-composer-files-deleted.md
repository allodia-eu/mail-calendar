# Copies of forwarded and reopened files are deleted on Windows

Platforms: windows
Bump: patch

> Each forward, reopened draft and Outbox edit wrote a copy of the message's files to disk, and
> nothing deleted it. A discarded composer now deletes its copies at once, and every other
> composer's go at the next launch, together with those earlier versions left behind.

Copies of attachments made for forwards and reopened drafts no longer pile up on disk.
