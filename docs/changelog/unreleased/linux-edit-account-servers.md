# Edit an account's servers and password in Settings → Accounts on Linux

Platforms: linux
Bump: minor

> A password account's page gains a Server and sign-in section: its servers, their security, the
> login and a new password. Saving tries them first and keeps nothing that does not connect, and
> an expired password is replaced here, calendar-and-contacts accounts included.

**English**

```
Settings → Accounts can now change an account's servers and password, trying them before anything is saved.
```
