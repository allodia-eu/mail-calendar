# The open message fits the screen

Platforms: ios
Bump: patch

> A compact width drew the six action buttons icon-only at the platform's largest control size, and
> six of those are wider than any iPhone. A row that outgrows its pane is not clipped on its own:
> it sets the width of the column it sits in, so the header, the invitation card and the body all
> hung off both edges of the display, taking the date and the overflow button with them. The
> control size is now measured the way the labels already were (`ViewThatFits` offers the next size
> down, so nothing is written down per device), the touch target rides on the glyph's own box so a
> smaller control is not a smaller target, and the pane's edge inset is one value the header,
> recipients, action row, attachment bar, invitation card and plain-text body all read.
