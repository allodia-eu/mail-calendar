# A calendar on a server of its own signs in through the browser the same way everywhere

Platforms: all
Bump: patch

> A mailbox's calendar and contacts on a server its sign-in does not reach can sign in at that
> server's own provider or with Nextcloud. The core now runs that sign-in as it runs an account's
> own: each platform shows it working, says it waits on the browser with a Cancel beside it, lets
> a second press replace a sign-in left open, and says on the form why one did not work.

**English**

```
Signing a separate calendar server in through your browser now shows that it is working, can be cancelled, and can be started again if you left the browser.
```
