# Discarding a message in a window of its own closes the window

Platforms: macos
Bump: patch

> Discard in a composer window removed the stored draft but left the window open, and its autosave
> then stored the draft again. The window now closes, and the core refuses any save of a
> composition that was discarded or sent.

**English**

```
Discarding a message in a window of its own now closes the window, and the draft no longer returns to Drafts.
```
