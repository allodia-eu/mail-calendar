# Save to Sent on IMAP accounts

Platforms: all
Bump: patch

> The IMAP connection wrapper did not forward the repair that files a delivered message's copy in
> Sent, so on an IMAP account "Save to Sent" always failed.

**English**

```
On IMAP accounts, Save to Sent now files the copy of a sent message that could not be saved in your Sent folder.
```

**Nederlands**

```
Bij IMAP-accounts zet Opslaan in Verzonden nu de kopie van een verzonden bericht die niet in je map Verzonden kon worden opgeslagen alsnog daar neer.
```

**Deutsch**

```
Bei IMAP-Konten legt „In ‚Gesendet‘ speichern“ jetzt die Kopie einer gesendeten Nachricht ab, die nicht in Ihrem Ordner „Gesendet“ gespeichert werden konnte.
```
