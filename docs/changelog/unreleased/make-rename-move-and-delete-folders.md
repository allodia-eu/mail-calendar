# Make, rename, move and delete folders

Platforms: all
Bump: minor

> Folder changes go through the engine's outbox: one made offline is drawn at once, marked as
> waiting, and sent on reconnect, after the engine has checked the folder is still where the user
> saw it. Delete puts a folder in Trash; deleting it from Trash removes it for good. Dragging is
> its own fragment, because it reaches only the platforms that drag.

**English**

```
You can now make, rename, move and delete folders from the folder pane, even offline.
```
