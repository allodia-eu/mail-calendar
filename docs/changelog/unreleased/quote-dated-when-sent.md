# A quoted message is dated when it was sent

Platforms: all
Bump: patch

> The quote's attribution and its `Sent:` line took the message's delivery time (IMAP internal
> date, JMAP `receivedAt`) ahead of its `Date:` header. They now take the header, and delivery only
> when a message carries none.

**English**

```
A reply or forward now gives the date the original message was sent, rather than the date it reached your mailbox.
```

**Nederlands**

```
Een antwoord of doorgestuurd bericht vermeldt nu de datum waarop het oorspronkelijke bericht is verzonden, in plaats van de datum waarop het in je postvak aankwam.
```

**Deutsch**

```
Eine Antwort oder Weiterleitung nennt jetzt das Datum, an dem die ursprüngliche Nachricht gesendet wurde, statt des Datums, an dem sie in Ihrem Postfach ankam.
```

**Français**

```
Une réponse ou un transfert indique désormais la date d’envoi du message d’origine, et non la date de son arrivée dans votre boîte aux lettres.
```

**Español**

```
Una respuesta o un reenvío indica ahora la fecha en que se envió el mensaje original, en lugar de la fecha en que llegó a tu buzón.
```

**Italiano**

```
Una risposta o un inoltro riporta ora la data in cui il messaggio originale è stato inviato, invece della data in cui è arrivato nella tua casella.
```

**Português**

```
Uma resposta ou um reencaminhamento indica agora a data em que a mensagem original foi enviada, em vez da data em que chegou à sua caixa de correio.
```
