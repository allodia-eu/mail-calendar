# An account's page shows a change running until it is done

Platforms: all
Bump: patch

> Switching one of an account's uses, linking another account or removing it in Settings now shows
> a spinner beside that control until the change is made, and holds the page's other controls
> meanwhile. A change that did not take says why.

**English**

```
Switching what an account is used for, linking it or removing it in Settings now shows that it is working until it is done.
```
