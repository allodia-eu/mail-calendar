# An account's servers follow the page's other controls

Platforms: all
Bump: patch

> Save on an account's servers shows a spinner while the new servers are tried and holds the
> page, says before it is pressed which field is left empty, and keeps what was typed when the
> servers are refused. A cleared outgoing server is refused rather than dropped, and a refused
> change is said in the person's language.

**English**

```
In Settings, saving an account's servers now shows that it is working, says which field still needs filling in, and keeps what you typed if the servers are refused.
```

**Nederlands**

```
In Instellingen laat het opslaan van de servers van een account nu zien dat het bezig is, zegt het welk veld nog ingevuld moet worden en blijft wat je typte staan als de servers worden geweigerd.
```

