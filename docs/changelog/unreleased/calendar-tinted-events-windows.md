# Calendar events are tinted in their calendar's colour on Windows

Platforms: windows
Bump: minor

> The tinted block, the wrapped title and the corner glyphs (docs/calendar.md §1, §4), as the
> other clients draw them, in the grid, the all-day bars, the month chips and the invitation
> card's preview. Labels are laid out once per page.

**English**

```
Calendar events are now tinted in their calendar's colour, show long titles in full where there is room, and mark repeating events.
```

