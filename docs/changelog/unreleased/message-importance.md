# Message importance: read it, and send it

Platforms: all
Bump: minor

> A high or low importance a sender set (`Importance`, or `X-Priority`) is now read on every
> account: the list row marks it, a conversation row is high when any message in it is, and an
> open message carries a banner. The composer's new Importance menu sends it, and a stored draft
> keeps it (docs/importance.md).

**English**

```
Messages sent with high or low importance are now marked in the list and say so when opened, and you can set a message’s importance while writing it.
```
