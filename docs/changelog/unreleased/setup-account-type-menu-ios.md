# The manual setup form's account type no longer opens a gap on iPhone

Platforms: ios
Bump: patch

> With "Calendar and contacts (CalDAV/CardDAV)" chosen, the "Account type" label no longer
> shares a row with the menu: squeezed, it wrapped into a column of single letters above the form.
> It sits above the menu whenever both do not fit side by side.
