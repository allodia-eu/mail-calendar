# The composer draws a message's text in the colour it is read in

Platforms: macos, ios, windows, android
Bump: patch

> The shared editor's light page takes the reading view's ink, and the quote attribution, sent
> without a colour of its own, is drawn in it rather than in grey (`docs/reading-dark-mode.md`,
> rule 10). The dark page itself is Linux's so far (`composer-dark-page.md`).

**English**

```
The text you write, and the line above a quoted message, now appear in the same colour as when the message is read.
```

**Nederlands**

```
De tekst die u schrijft, en de regel boven een geciteerd bericht, verschijnen nu in dezelfde kleur als wanneer het bericht wordt gelezen.
```

**Deutsch**

```
Der Text, den Sie schreiben, und die Zeile über einer zitierten Nachricht erscheinen jetzt in derselben Farbe wie beim Lesen der Nachricht.
```

**Français**

```
Le texte que vous rédigez, ainsi que la ligne au-dessus d’un message cité, s’affichent désormais dans la même couleur qu’à la lecture du message.
```

**Español**

```
El texto que escribe, y la línea sobre un mensaje citado, se muestran ahora en el mismo color que al leer el mensaje.
```

**Italiano**

```
Il testo che scrive, e la riga sopra un messaggio citato, ora appaiono nello stesso colore di quando il messaggio viene letto.
```

**Português**

```
O texto que escreve, e a linha acima de uma mensagem citada, aparecem agora na mesma cor de quando a mensagem é lida.
```
