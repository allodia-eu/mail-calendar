# Answer routes follow the calendar server's address set

Platforms: all
Bump: patch

> An answer to an invitation sent to an address the calendar server does not schedule as is now
> emailed by the app, also where mail and calendar share one account; on Outlook and Google an
> alias the server leaves unnamed no longer blocks a meeting or its answer.

**English**

```
An answer to an invitation sent to an address your calendar server does not handle is now emailed to the organiser rather than only saved.
```
