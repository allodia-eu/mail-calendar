# Every file attached to a message stays in reach

Platforms: macos, ios, linux
Bump: patch

> The Apple composer's file list grew under the editor with no ceiling: on macOS the column did not
> scroll and the editor kept 240 pt, so the third file was cut off in a window of ordinary height,
> and on iPhone and iPad the editor was sized without the list, which sat below the visible area.
> The list now hugs its rows up to four and scrolls past them, scrolling to a file just added, and
> the editor takes what the header and the list leave, the column scrolling once it reaches its
> floor. Linux's list sat above the editor with no ceiling either, and now scrolls past three rows.

**English**

```
Every file you attach to a message stays visible and can be removed, however many you add.
```
