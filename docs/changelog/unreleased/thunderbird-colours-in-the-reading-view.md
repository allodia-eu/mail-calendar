# Thunderbird's colours and fonts show when reading, and Outlook's signature reads as text

Platforms: all
Bump: patch

> Thunderbird writes a colour, a size or a typeface as a `<font>` element, which the reading view's
> sanitiser removed, so its text showed in the body's colour and size. The element is kept now.
> Word marks a signature's first line with a bookmark, which the base sheet coloured as a link.
