# Pasting lists from Word, merged cells and pictures

Platforms: all
Bump: patch

> Closes three of the paste gaps composer-security.md listed. Word's list paragraphs (`mso-list`)
> become real lists; a table cell merged across rows no longer shifts the row below it; and a
> picture the pasted markup carries inline (`data:`) is kept, so text and a picture copied together
> inside a message move together. A picture the markup names by URL is still dropped, now stated
> as a rule, as is the plain text an Android keyboard's clipboard strip types in.

**English**

```
Lists pasted from Word or Outlook stay lists, merged table cells no longer shift the rows below them, and a picture copied with text inside a message moves with it.
```

