# The email keyboard in address fields

Platforms: android, windows, linux
Bump: patch

**English**

```
Address fields, such as To and the invitee field, now bring up the email keyboard with @ at hand, and no longer correct what you type.
```

**Nederlands**

```
Adresvelden, zoals Aan en het veld voor genodigden, openen nu het e-mailtoetsenbord met @ binnen handbereik, en verbeteren niet meer wat je typt.
```

**Deutsch**

```
Adressfelder wie „An“ und das Feld für Eingeladene öffnen jetzt die E-Mail-Tastatur mit @ griffbereit und korrigieren Ihre Eingabe nicht mehr.
```

**Français**

```
Les champs d’adresse, comme À et le champ des invités, affichent désormais le clavier e-mail avec @ à portée de main, et ne corrigent plus ce que vous saisissez.
```

**Español**

```
Los campos de dirección, como Para y el de invitados, muestran ahora el teclado de correo con la @ a mano, y ya no corrigen lo que escribes.
```

**Italiano**

```
I campi indirizzo, come A e il campo degli invitati, aprono ora la tastiera email con la @ a portata di mano, e non correggono più ciò che scrivi.
```

**Português**

```
Os campos de endereço, como Para e o campo de convidados, abrem agora o teclado de email com o @ à mão, e já não corrigem o que escreve.
```
