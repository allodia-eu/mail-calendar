# A separate calendar server says what did not connect, and a slow one is given time

Platforms: all
Bump: patch

> Moving the calendar and contacts to an account of their own gave a slow address book server
> 10 seconds across one connect per book in turn, and said "could not be reached" in English. The
> books now connect side by side, an account without mail waits up to 30 seconds, and a failure
> names the use in the person's language. A browser that comes back from an older, unfinished
> sign-in is now said as such rather than as a failed sign-in.

**English**

```
Setting up a calendar or address book on a server of its own now waits longer for a slow server and says which one did not connect, and a sign-in the browser returned from an earlier attempt now says to sign in again.
```

**Nederlands**

```
Een agenda of adresboek op een eigen server instellen wacht nu langer op een trage server en zegt welke geen verbinding kreeg, en een aanmelding waarbij de browser terugkwam van een eerdere poging vraagt nu om opnieuw aan te melden.
```

