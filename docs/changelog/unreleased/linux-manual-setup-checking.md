# Linux's manual setup no longer says it is still checking

Platforms: linux
Bump: patch

> The manual account form kept "Checking how you can sign in…" on screen after a server that
> takes a password had answered, so it read as still waiting. The form now says nothing while the
> server is asked, and only what an answer adds.
