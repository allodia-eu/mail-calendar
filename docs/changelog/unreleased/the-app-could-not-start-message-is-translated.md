# The "couldn't open the app" message is in your language

Platforms: windows
Bump: patch

> Five guards for an app object that is not there yet, across the account setup, the Google
> sign-in, the Allodia sign-in and the subscription writes, each returned the same English sentence
> written in the file. Everything around them came from the catalog, so a Dutch or German reader
> got one line of English in the middle of their own language, and only in the state where
> something had already gone wrong. It is one catalog key now, in all seven locales.
