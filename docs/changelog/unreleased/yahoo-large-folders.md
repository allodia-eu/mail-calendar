# A Yahoo folder shows every message within the sync depth

Platforms: all
Bump: patch

> Yahoo answers a date search matching more than 1000 messages with the newest 1000 and no sign
> that more exist, so with the default sync depth (6 months on desktop, 3 on mobile) a busier
> folder showed only its newest 1000. The engine now reads each message's date itself when a
> search comes back at the server's limit.

```
On a Yahoo account, a folder with more than 1000 messages within the sync depth now shows all of them, not only the newest 1000.
```
