# The unified Inbox count follows the account Inboxes on Windows

Platforms: windows
Bump: patch

> All Accounts › Inbox was redrawn with the account rows, before the snapshot's sum was read, so
> a sync that moved only the counts left it one snapshot behind the Inboxes under it until
> something else redrew the pane.

**English**

```
The unread count on All Accounts › Inbox now changes as soon as the count on an account’s Inbox does.
```
