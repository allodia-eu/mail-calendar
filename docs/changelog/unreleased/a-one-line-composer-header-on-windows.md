# A one-line composer header on Windows

Platforms: windows
Bump: patch

> From, To, Cc, Bcc and Subject each put their label above the field and a pill row above the input,
> so the header took about twice the height a mail client's does and a short window had little left
> for the message. Each is now one line, the label beside the field and the pills flowing inline with
> the address being typed.

**English**

```
On Windows, the composer's From, To, Cc, Bcc and Subject now take one line each, leaving more room for your message.
```
