# A font size picked with nothing selected

Platforms: all
Bump: patch

> The size command marks what it touched with the largest legacy size and rewrites it to the real
> one, but with only a caret nothing was touched yet, so the next words were typed, and sent, at
> 48px. The nearest real size is drawn instead, and the exact one stamped as the typing starts.

**English**

```
Choosing a font size with nothing selected now applies that size to what you type next, rather than a much larger one.
```
