# Changing a subscription shows that it is working

Platforms: all
Bump: patch

> The subscription section in Settings is read and changed by the core. Cancelling, switching
> period, restarting and starting a checkout each show a spinner on their button until the
> section has been read again, a second change cannot start meanwhile, the section is read again
> when the app comes back to the front, and a store's own page is offered when that store has put
> the subscription on hold or paused it.

**English**

```
Changing your subscription in Settings now shows that it is working, and the subscription is brought up to date when you return to the app.
```
