# Use a calendar from another account with a JMAP account on Linux

Platforms: linux
Bump: minor

> Most JMAP servers offer no calendar while JMAP Calendars is a draft, so setup offers to link one,
> including the calendar server found beside the mail server.

**English**

```
On Linux, a JMAP account whose server has no calendar can use one from another account, and setup offers the calendar server it found for your address.
```

**Nederlands**

```

```
