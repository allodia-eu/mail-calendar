# Invitations can be answered on Microsoft, Google and OAuth JMAP calendars

Platforms: all
Bump: patch

> The app's token-refreshing wrappers for these three calendars did not pass an invitation
> answer, or the lookup of the account's own calendar addresses, to the engine, so accepting,
> declining or answering "maybe" failed as unsupported.

**English**

```
Accepting, declining or answering "maybe" to a meeting now works on Microsoft, Google and other OAuth calendar accounts.
```
