# A sign-in closed in the browser can be tried again

Platforms: macos, ios, android, windows
Bump: patch

> Closing the browser during a mail server's sign-in in setup could leave the sign-in button
> spinning or disabled (Android until the app was restarted, macOS with no way back, Windows for
> five minutes), and going back while it started could still open the browser or add the account
> afterwards. A fresh press now starts over, a way back is offered, and an abandoned sign-in
> opens and adds nothing.

**English**

```
A sign-in closed in the browser while adding an account can now be tried again straight away, and one you left no longer opens the browser or adds the account afterwards.
```
