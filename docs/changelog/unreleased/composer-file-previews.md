# A composer's files show a picture of themselves and their total size

Platforms: all
Bump: minor

> Each file's tile is one line: a small picture of the file when it is an image, its name cut in
> the middle so the end and the extension stay, and its size; above the tiles, how many files there
> are and how large together (`docs/composer-layout.md`, rule 4).

**English**

```
Attached pictures show a small preview, long file names keep their ending, and the number of files and their total size are shown above them.
```
