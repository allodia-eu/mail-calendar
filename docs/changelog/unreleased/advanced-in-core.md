# Settings → Advanced says what a reset and assistant access came to

Platforms: all
Bump: patch

> Resetting the local database keeps Settings open: the button shows it is working until mail is
> downloaded again, then says whether the reset worked, and a second press waits for the first.
> On a desktop, AI assistant access says when it is starting and when another copy of the app is
> already serving assistants, instead of reading as running.

**English**

```
Resetting the local database now keeps Settings open and says whether it worked, and AI assistant access says when another copy of the app is already serving assistants.
```
