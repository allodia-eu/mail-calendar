# Choose what an account is used for, and link it, while setting it up on Android

Platforms: android
Bump: minor

> The found card offers mail, calendar and contacts as the core decided them, each on where its
> server was found and with a field for one that was not. A domain with a calendar and address
> book and no mail server gets a card of its own, and the manual form gains an address-book field
> and a "Calendar and contacts" type. A Microsoft or Google sign-in offers the same choice first and
> asks the provider for those alone; a use it withheld is said on the account's page once setup is
> done. A JMAP account is asked what it is used for once its server has said. Setup ends on a
> skippable step that links the new account to another, with "Add another account", and each
> account added is asked its name in turn.

**English**

```
Setting up an account on Android lets you choose mail, calendar and contacts, add a calendar and contacts server without mail, and link the account to another.
```
