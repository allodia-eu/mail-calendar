# Sign in with Nextcloud on Android

Platforms: android
Bump: minor

> A calendar and contacts server that says it is Nextcloud is offered Nextcloud's own browser
> sign-in (Login Flow v2) on the found card, the manual form, the separate-server step and the
> account's page, instead of a hand-made app password (`docs/nextcloud-sign-in.md`).

**English**

```
A calendar and address book on a Nextcloud server can now be added by signing in through Nextcloud in your browser, single sign-on included, without making an app password yourself.
```

**Nederlands**

```
Een agenda en adresboek op een Nextcloud-server voeg je nu toe door je via Nextcloud in je browser aan te melden, ook met single sign-on, zonder zelf een app-wachtwoord te maken.
```
