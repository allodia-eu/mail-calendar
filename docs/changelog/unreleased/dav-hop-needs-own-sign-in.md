# A calendar that leads past the provider's sign-in says so

Platforms: all
Bump: patch

> A calendar or address book whose discovery leads to a host the account's grant may not take
> its token to (`docs/mail-oauth.md` rule 10) now reports that the use needs a sign-in of its own
> (`AccountError::DavNeedsOwnSignIn`), rather than that the server has none for the account.

**English**

```
When a calendar or address book server sends the app on to a server your provider's sign-in does not cover, the account now says that this use needs a sign-in of its own, rather than that the server has nothing for the account.
```

**Nederlands**

```
Als een agenda- of adresboekserver de app doorstuurt naar een server waarvoor de aanmelding bij uw provider niet geldt, meldt het account nu dat dit onderdeel een eigen aanmelding nodig heeft, in plaats van dat de server niets voor het account heeft.
```

**Deutsch**

```
Wenn ein Kalender- oder Adressbuchserver die App an einen Server weiterleitet, für den die Anmeldung bei Ihrem Anbieter nicht gilt, zeigt das Konto jetzt an, dass dafür eine eigene Anmeldung nötig ist, statt zu melden, der Server habe nichts für das Konto.
```
