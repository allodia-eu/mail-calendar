# Add a Teams or Talk meeting through a connected account

Platforms: all
Bump: minor

> An account gains a Video meetings use, off until switched on: a Microsoft work account makes
> Teams meetings (switching it on asks Microsoft for `OnlineMeetings.ReadWrite`) and a Nextcloud
> account makes Talk meetings with its own app password. Each adds a choice, named with the
> account's address, to every writable calendar's Video meeting row. The meeting is made before
> the event is written, and deleted again if the event could not be saved.

**English**

```
Add a Microsoft Teams or Nextcloud Talk meeting to an event on any calendar, through a work or Nextcloud account you switch video meetings on for.
```
