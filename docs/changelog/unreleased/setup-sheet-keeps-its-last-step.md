# Setup no longer flashes its first screen as it closes

Platforms: macos
Bump: patch

> Ending setup from the link step, the uses step or the separate-server step cleared the step at
> once, so the closing sheet drew "Add your account" for the frames its dismissal took. The sheet
> now keeps the step it ended on until setup is next opened.
