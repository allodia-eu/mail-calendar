# Preparing the Linux app as a snap

Platforms: linux
Bump: patch

> A strictly confined snap on core26 and the GNOME extension, built by
> `clients/linux/package-snap.sh`. The listing waits on the Snap Store's review of the name, so
> the note claims the preparation and not the availability.
