# A preview without the stylesheet

Platforms: all
Bump: patch

> An HTML-only message whose stylesheet is written `<style type="text/css">` showed that stylesheet
> as the start of its text: in the message list's preview line on IMAP accounts, in the plain-text
> reading view and in search. The text now starts with the message itself. A message already
> synced keeps the text it was stored with.

**English**

```
The message list no longer shows a message's formatting code instead of its first lines.
```
