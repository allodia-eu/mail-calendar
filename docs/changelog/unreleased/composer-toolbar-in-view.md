# The formatting toolbar stays in view while writing a long message

Platforms: macos, windows, linux
Bump: minor

> On a desktop the editor draws its toolbar where the composer's visible part starts while the
> message runs on under it, and the line being typed is always brought fully into view
> (`docs/composer-layout.md`, rules 6 and 7).

**English**

```
The formatting toolbar stays in view while you write a long message, and the line you are typing is never cut off at the bottom of the window.
```

```
De opmaakbalk blijft in beeld terwijl je een lang bericht schrijft, en de regel die je typt valt nooit meer half onder de rand van het venster.
```

```
Die Formatierungsleiste bleibt sichtbar, während Sie eine lange Nachricht schreiben, und die Zeile, die Sie tippen, wird am unteren Fensterrand nicht mehr abgeschnitten.
```
