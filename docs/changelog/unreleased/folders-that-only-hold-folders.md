# Folders that only hold folders

Platforms: all
Bump: patch

> An IMAP folder that exists only to hold other folders (Gmail's `[Gmail]`, a parent created for
> its children) was synced on every pass and failed, took dropped mail the server then refused,
> and was offered for push.

**English**

```
Folders that only hold other folders, such as Gmail's [Gmail], are no longer offered as a place to move mail or to watch for new mail.
```

**Nederlands**

```
Mappen die alleen andere mappen bevatten, zoals [Gmail] bij Gmail, worden niet meer aangeboden om e-mail naartoe te verplaatsen of om op nieuwe e-mail te controleren.
```

**Deutsch**

```
Ordner, die nur andere Ordner enthalten, etwa [Gmail] bei Gmail, werden nicht mehr als Ziel zum Verschieben von E-Mails oder zur Überwachung auf neue E-Mails angeboten.
```

**Français**

```
Les dossiers qui ne contiennent que d'autres dossiers, comme [Gmail] chez Gmail, ne sont plus proposés pour y déplacer des e-mails ni pour y surveiller l'arrivée de nouveaux e-mails.
```

**Español**

```

```

**Italiano**

