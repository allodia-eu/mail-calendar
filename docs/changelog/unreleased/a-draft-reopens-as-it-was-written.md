# A draft reopens as it was written

Platforms: all
Bump: minor

> A draft resumed from Drafts, and a message moved back out of the Outbox with Edit, opened as
> plain text, so its formatting, pictures, quoted original and signature were lost on the next
> save. Both now open with all of them, and a reopened reply stays in its conversation.

**English**

```
A draft you open again, or a message you edit from the Outbox, now keeps its formatting, pictures, quoted message and signature.
```
