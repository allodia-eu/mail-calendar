# Yahoo calendars and address books sync, and Fastmail address books appear

Platforms: all
Bump: minor

> Yahoo's calendar and address book servers answer no incremental sync, list some events under a
> doubly encoded address, and refuse a request that names no client. Fastmail announces its
> address books on a second `DAV` header line, which was not read. The engine now handles all four,
> and every request names this app with its version.
