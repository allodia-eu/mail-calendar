# Add accounts from Settings on Linux

Platforms: linux
Bump: patch

> The folder pane's "+" button is gone: Settings → Accounts is where an account is added, beside
> where each one is changed and removed.

**English**

```
On Linux, you add another account from Settings → Accounts, where your accounts are also changed and removed, rather than from a button above the folders.
```

**Nederlands**

```
Op Linux voeg je een extra account toe via Instellingen → Accounts, waar je accounts ook worden gewijzigd en verwijderd, in plaats van via een knop boven de mappen.
```

**Deutsch**

```
Unter Linux fügen Sie ein weiteres Konto über Einstellungen → Konten hinzu, wo Ihre Konten auch geändert und entfernt werden, statt über eine Schaltfläche über den Ordnern.
```

**Français**

```
Sous Linux, vous ajoutez un autre compte depuis Réglages → Comptes, où vos comptes sont aussi modifiés et supprimés, plutôt que depuis un bouton au-dessus des dossiers.
```

**Español**

```
En Linux, añades otra cuenta desde Ajustes → Cuentas, donde también se cambian y eliminan tus cuentas, en lugar de desde un botón encima de las carpetas.
```

**Italiano**

```
Su Linux, aggiungi un altro account da Impostazioni → Account, dove i tuoi account vengono anche modificati e rimossi, invece che da un pulsante sopra le cartelle.
```

**Português**

```
No Linux, adiciona outra conta em Definições → Contas, onde as suas contas também são alteradas e removidas, em vez de num botão acima das pastas.
```
