# Saving a sender name no longer pauses the app

Platforms: all
Bump: patch

> Setting the name an account sends under waited for the provider to take its copy before the
> app could draw again, so a slow server froze the window, on every platform. The name is now
> stored at once and the provider's copy follows in the background. On Linux, starting an Allodia
> sign-in also read the service's metadata on the window's own thread; it now runs beside it, and
> the card shows that it is signing in from the press.

```
Saving the name your mail is sent under no longer pauses the app while the server answers.
```
