# Choose the default calendar on Mac, iPhone, iPad and Windows

Platforms: macos, ios, windows
Bump: minor

> The setting was already the core's and drawn on Android and Linux. Apple and Windows now draw
> it too, and their new-event paths open on the calendar the core marks rather than on the first
> writable one.

**English**

```
Choose which calendar a new event goes in, under Settings → Calendar.
```

**Nederlands**

```
Kies in welke agenda een nieuwe afspraak komt, onder Instellingen → Agenda.
```

**Deutsch**

```
Wählen Sie unter Einstellungen → Kalender, in welchem Kalender ein neuer Termin angelegt wird.
```

**Français**

```
Choisissez dans quel calendrier un nouvel événement est créé, sous Réglages → Calendrier.
```

**Español**

```
Elige en qué calendario se crea un evento nuevo, en Ajustes → Calendario.
```

**Italiano**

```
Scegli in quale calendario viene creato un nuovo evento, in Impostazioni → Calendario.
```

**Português**

```
Escolha em que calendário é criado um novo evento, em Definições → Calendário.
```
