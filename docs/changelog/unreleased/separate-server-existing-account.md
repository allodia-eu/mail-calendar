# A calendar server's password is checked before linking to an account already set up for it

Platforms: all
Bump: patch

> Connecting a calendar on a server of its own, where an account for that server and login is
> already set up, links the mailbox to it only once the server has taken the password typed. A
> wrong password is said on the form and changes nothing.

**English**

```
A wrong password for a separate calendar server is now refused, even when an account for that server is already set up.
```
