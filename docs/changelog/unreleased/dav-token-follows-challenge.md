# Calendar and contacts on a signed-in account at Soverin

Platforms: all
Bump: patch

> An OAuth account presents its access token to CalDAV and CardDAV as Bearer, and Soverin's
> sabre/dav answers that with a Basic-only challenge while accepting the same token as the Basic
> password. The engine now reads the challenge and switches; this side hands it the login.

**English**

```
Calendar and contacts now also sync on an account added by signing in with your provider at providers such as Soverin, where only mail did before.
```
