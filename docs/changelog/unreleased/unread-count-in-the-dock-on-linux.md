# Unread count in the dock on Linux

Platforms: linux
Bump: minor

> Unity's `LauncherEntry.Update` carries `unified_unread` to the docks that read it (Ubuntu Dock,
> KDE Plasma, Plank), and the count is taken off when the app quits (`docs/app-badge.md`). GNOME
> Shell without a dock extension draws nothing, which is why the note names the docks.

```
Docks that show counts on their icons, such as Ubuntu Dock and KDE Plasma's, now show how many messages in your inboxes are unread.
```
