# A mail server sign-in can be tried again on Android

Platforms: android
Bump: patch

> Closing the browser without signing in to a mail server that offers sign-in left the setup
> button spinning and disabled. Returning to the app now clears it, and pressing it again starts a
> new sign-in. Going back from the card while the sign-in was still starting opened the browser
> anyway a moment later; it no longer does.

**English**

```
A mail server sign-in can be tried again after closing the browser, and going back while it starts no longer opens the browser later.
```
