# A dismissed mail server sign-in can be tried again on Android

Platforms: android
Bump: patch

> Closing the browser without signing in to a mail server that offers sign-in left the setup
> button spinning and disabled. Returning to the app now clears it, and pressing it again starts a
> new sign-in.

**English**

```
Closing the browser during a mail server sign-in no longer leaves the sign-in button spinning; you can press it again.
```
