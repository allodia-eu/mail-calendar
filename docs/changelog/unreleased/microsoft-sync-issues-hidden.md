# Microsoft 365's Sync Issues folder is no longer listed

Platforms: all
Bump: patch

> Sync Issues and the folders under it hold the service's own records of failed synchronisations,
> no mail anyone filed: they get no row and are not synced. Conversation History stays, as an
> ordinary folder.

**English**

```
On Microsoft 365 accounts, the Sync Issues folder, which holds only the service's own records, is no longer listed or downloaded.
```
