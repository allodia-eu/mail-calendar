# The Allodia sign-in notice turns urgent a week before a paid feature stops

Platforms: all
Bump: patch

> The core now reads the Allodia entitlement itself, in the background, and keeps the answer beside
> the store. While the Allodia sign-in is refused, the stored answer still grants a paid capability
> for 30 days; in the last seven, the notice saying the sign-in ended is drawn as Blocked rather
> than Degraded, because signing in again is what keeps the capability.

```
If your Allodia sign-in has ended and a paid feature will stop within a week, the notice now says so in the warning colour.
```
