# A default video meeting per account

Platforms: all
Bump: minor

> The default is stored per account and resolved by the core against what each calendar
> offers. It is applied only once a new event has an invitee, so an event of the person's own
> makes no meeting at any service, and a pick in the editor's row always outranks it.

**English**

```
Choose a default video meeting for each account under Settings → Videoconferencing: a new event gets it as soon as you invite someone.
```

**Nederlands**

```
Kies per account een standaard videovergadering onder Instellingen → Videovergaderen: een nieuwe afspraak krijgt die zodra je iemand uitnodigt.
```

**Deutsch**

```
Wählen Sie unter Einstellungen → Videokonferenzen für jedes Konto eine Standard-Videokonferenz: Ein neuer Termin erhält sie, sobald Sie jemanden einladen.
```

**Français**

```
Choisissez une visioconférence par défaut pour chaque compte sous Réglages → Visioconférence : un nouvel événement la reçoit dès que vous invitez quelqu’un.
```

**Español**

```
Elige una videoconferencia predeterminada para cada cuenta en Ajustes → Videoconferencia: un evento nuevo la recibe en cuanto invitas a alguien.
```

**Italiano**

```
Scegli una videoconferenza predefinita per ogni account in Impostazioni → Videoconferenze: un nuovo evento la riceve appena inviti qualcuno.
```

**Português**

```
Escolha uma videoconferência predefinida para cada conta em Definições → Videoconferência: um novo evento recebe-a assim que convida alguém.
```
