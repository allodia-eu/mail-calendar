# Settings says when calendar or contacts did not connect

Platforms: all
Bump: minor

> A calendar or address book failure beside a working mailbox was only logged, and a contacts
> failure was dropped in the core. Each use now carries why it failed, the account's page says it,
> an unreachable one is retried on Refresh, and the calendar no longer reads a failed calendar as
> an empty week.

**English**

```
When your calendar or contacts can’t connect, the account’s page in Settings now says why, and a server that couldn’t be reached is tried again when you refresh.
```
