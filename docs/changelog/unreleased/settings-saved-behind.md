# Settings are saved without holding up the window, and a failed save is said

Platforms: all
Bump: patch

> Every preference is applied by the core at once and written to the preferences file in the
> background, so no control waits on the disk. A write that fails raises a notice with Try again
> instead of being dropped, and the calendar's default zoom offers the same choices on every
> platform.

**English**

```
Changing a setting no longer waits on saving it, and if a setting can’t be saved you are told and can try again.
```
