# The reading spinner keeps its size on Linux

Platforms: linux
Bump: patch

> The reading pane's loading spinner was a stack page of its own, so it was allocated, and drawn,
> as large as the whole body area. It is now 32 px and centred.

**English**

```
The indicator shown while a message loads is now a small spinner in the middle of the reading pane, rather than one that filled it.
```
