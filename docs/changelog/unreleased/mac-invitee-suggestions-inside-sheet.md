# An event's invitee suggestions stay inside the editor on a Mac

Platforms: macos
Bump: patch

> The suggestion list was hung under the input with no limit on its height, so under the invitee
> field, at the foot of the event editor, it ran past the form and under the sheet's bar: the bar's
> divider crossed the list and Cancel was drawn over it. The Mac now places the list as the phone
> does, below the input while there is room for about three suggestions and above it otherwise,
> never taller than that room.

**English**

```
When you invite people to an event, the address suggestions no longer run under Cancel and Save.
```
