# Signing a Microsoft or Google account in again keeps it on Linux

Platforms: linux
Bump: minor

> Signing in again re-added the account, resetting how much mail it keeps and downloading it
> afresh. It now replaces the sign-in in place, from the main window's prompts and from a new
> Sign-in section on the account's page in Settings → Accounts, and switching on a use the
> provider has not allowed asks for it in the browser.

**English**

```
Signing a Microsoft or Google account in again keeps its mail and settings, and Settings → Accounts can now ask the provider for a use it has not allowed.
```
