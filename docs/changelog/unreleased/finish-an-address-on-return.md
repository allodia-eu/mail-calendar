# Return or leaving the field finishes an address

Platforms: macos, ios, android, windows, linux
Bump: patch

**English**

```
An address typed into To, Cc or Bcc now becomes its own recipient when you press Return or move to another field, not only after a comma.
```

**Nederlands**

```
Een adres dat je in Aan, Cc of Bcc typt, wordt nu een eigen ontvanger zodra je op Return drukt of naar een ander veld gaat, niet alleen na een komma.
```

**Deutsch**

```
Eine in An, Cc oder Bcc eingegebene Adresse wird jetzt zu einem eigenen Empfänger, sobald Sie die Eingabetaste drücken oder in ein anderes Feld wechseln, nicht erst nach einem Komma.
```

**Français**

```
Une adresse saisie dans À, Cc ou Cci devient désormais un destinataire à part entière dès que vous appuyez sur Retour ou passez à un autre champ, et non plus seulement après une virgule.
```

**Español**

```

```

**Italiano**

