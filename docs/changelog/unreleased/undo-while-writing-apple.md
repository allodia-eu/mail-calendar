# Undo and redo while writing, on a Mac, iPhone and iPad

Platforms: macos, ios
Bump: minor

> The body's history is the shared bundle's (`history.ts`), which the Edit menu, shaking and the
> shortcut bar now read and step too (`EditorUndoManager`), and the recipient fields keep a step
> per address (`RecipientHistory`), so a finished address no longer comes back as a second
> recipient.

**English**

```
Undo and redo now work while writing: ⌘Z, the Edit menu, a shake or the iPad's shortcut bar takes back the newest change in the message or the field you are in, ⇧⌘Z puts it back, and a removed recipient comes back whole.
```
