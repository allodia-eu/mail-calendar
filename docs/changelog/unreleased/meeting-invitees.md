# Invite people to an event

Platforms: all
Bump: minor

> The editor over the core's meeting commands. It is offered only on a calendar whose server sends
> the invitations (Graph, Google, JMAP, CalDAV with auto-scheduling), because a plain CalDAV server
> stores a meeting and tells nobody on it.

**English**

```
Invite people to a new event, as required or optional, and change who is invited to a meeting you organise. The calendar's server sends the invitations.
```

**Nederlands**

```
Nodig mensen uit voor een nieuwe afspraak, verplicht of optioneel, en wijzig wie er is uitgenodigd voor een vergadering die je organiseert. De server van de agenda verstuurt de uitnodigingen.
```

**Deutsch**

Laden Sie Personen zu einem neuen Termin ein, als erforderlich oder optional, und ändern Sie, wer zu einer von Ihnen organisierten Besprechung eingeladen ist. Der Server des Kalenders versendet die Einladungen.
