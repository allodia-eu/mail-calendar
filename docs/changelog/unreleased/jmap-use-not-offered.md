# Say in Settings when a JMAP server does not offer a use, on Mac, iPhone, iPad and Windows

Platforms: macos, ios, windows
Bump: patch

> A JMAP server without a calendar or contacts left that use reading as on in Settings → Accounts.
> It now reads as not offered, and cannot be switched on.

**English**

```
Settings shows when a JMAP server does not offer calendar or contacts, rather than showing them as on.
```
