# A message's attachments can be reached with the keyboard

Platforms: linux
Bump: patch

> The attachment rows under an open message sat outside a list, so the keyboard skipped them and
> their Open and Save buttons could be used only with a pointer. They are now a group like every
> other list of rows in the app.

**English**

```
The attachments of an open message, and their Open and Save buttons, can now be reached with the keyboard.
```
