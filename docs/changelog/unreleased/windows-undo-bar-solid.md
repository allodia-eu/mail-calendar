# On Windows, the bar offering to undo an archive or delete no longer lets the list show through

Platforms: windows
Bump: patch

> The undo bar and the sending bar float over the message list, and InfoBar's informational tint is
> nearly transparent, so the rows beneath read through them. Both now sit on a solid ground.

**English**

```
On Windows, the bar that offers to undo an archive or delete, and the one shown while a message sends, are now solid, so the list behind them no longer shows through.
```
