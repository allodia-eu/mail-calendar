# Tell apart accounts with one address

Platforms: all
Bump: patch

> A mailbox and the calendar account split off from it share an address, so its links read as
> pointing at itself. Settings now names each with its kind, or its server where the kinds match.

**English**

```
Settings tells apart two accounts with the same address by naming their kind or server.
```
