# An error shown as Settings opens is drawn above it

Platforms: linux
Bump: patch

> An error raised in the same moment Settings opens, such as a refused server change asked from
> the calendar or a sign-in that failed during setup, was presented before Settings had drawn,
> and a desktop that stacks windows in the order they appear left it hidden behind Settings.

**English**

```
An error shown as Settings opens now appears in front of it rather than behind it on desktops such as Sway.
```
