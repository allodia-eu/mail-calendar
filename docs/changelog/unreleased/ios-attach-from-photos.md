# Attach pictures and films from the photo library on iPhone and iPad

Platforms: ios
Bump: patch

> Attach in the composer and Add image in the signature editor now offer the photo library beside
> Files. A photograph taken as HEIC is attached as a JPEG, and one that could not be fetched is
> named in the composer.
