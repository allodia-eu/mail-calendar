# A calendar page more than a few months back or a year ahead loads

Platforms: all
Bump: patch

> The calendar expanded a fixed window around today, and a page outside it said "Loading this
> period…" for good. Asking for such a page now widens the window to it for the session.

**English**

```
Calendar weeks and months more than four months back or a year ahead now load, instead of showing "Loading this period…".
```

**Nederlands**

```
Weken en maanden in de agenda die meer dan vier maanden terug of een jaar vooruit liggen, worden nu geladen in plaats van ‘Deze periode laden…’ te blijven tonen.
```

**Deutsch**

```
Kalenderwochen und -monate, die mehr als vier Monate zurück oder ein Jahr voraus liegen, werden jetzt geladen, statt „Dieser Zeitraum wird geladen…“ anzuzeigen.
```

**Français**

```
Les semaines et les mois du calendrier situés à plus de quatre mois en arrière ou d’un an en avant se chargent désormais, au lieu d’afficher « Chargement de cette période… ».
```

**Español**

```

**Italiano**

```
