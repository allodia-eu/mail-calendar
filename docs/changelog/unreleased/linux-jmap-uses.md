# Choose what a JMAP account is used for after signing in on Linux

Platforms: linux
Bump: minor

> A JMAP server says which of mail, calendar and contacts an account has only after the sign-in,
> so that is when the choice is offered. Settings says when the server does not offer a use,
> rather than showing it as on.

**English**

```
After you sign in to a JMAP account on Linux, you choose which of the mail, calendar and contacts its server offers you want to use, and Settings shows what the server does not offer.
```

**Nederlands**

```
Nadat je op Linux bij een JMAP-account bent ingelogd, kies je welke van de e-mail, agenda en contacten die de server aanbiedt je wilt gebruiken, en Instellingen toont wat de server niet aanbiedt.
```

**Deutsch**

```
Nach der Anmeldung bei einem JMAP-Konto unter Linux wählen Sie, welche der vom Server angebotenen Dienste E-Mail, Kalender und Kontakte Sie nutzen möchten, und die Einstellungen zeigen, was der Server nicht anbietet.
```
