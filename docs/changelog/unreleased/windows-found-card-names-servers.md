# The Windows found card names its servers

Platforms: windows
Bump: patch

> The found card drew the detected servers as the manual form's editable fields; it now names them
> under the mail toggle, as the other clients do, and "Set up manually" still edits them.

**English**

```
When adding an account, the servers we found are now listed for you to confirm instead of shown as fields to fill in.
```

```

```
