# Paste a picture straight into a message

Platforms: android, linux
Bump: minor

> The bytes travel inside the editor document as a `data:` URI and the shared core turns them into
> a `cid:` `multipart/related` part on send, which is the same destination a signature's logo
> already reaches. Doing it that way keeps the whole path in the shared bundle and shared Rust, so
> the remaining three clients inherit it without a host bridge each. Deliberately left out: a
> toolbar button that browses for a picture, and any resizing of what was pasted.

**English**

```
Paste a screenshot or a photo straight into a message and it appears where you are typing, sent
as part of the message rather than as a file to download.
```
