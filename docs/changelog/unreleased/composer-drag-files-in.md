# Drag files onto a message you are writing

Platforms: android, linux
Bump: minor

> The page refuses the drop and the host takes it: web code only ever sees a `File` with no path,
> which can neither be streamed from disk on send nor listed for removal. A picture is the one case
> with two sensible answers, so the client asks in the reader's terms rather than choosing for
> them; the "show it" answer reuses the paste path, so the two cannot behave differently.

**English**

```
Drag files onto a message you are writing to attach them. Drag a picture and you are asked whether
to show it in the message or send it as a file to download.
```
