# The calendar's arrows count every press on Windows

Platforms: windows
Bump: patch

> A press of the calendar's previous or next arrow while the grid was still sliding from the last
> one stepped from wherever the slide had got to, so quick presses travelled less than asked and
> the grid could rest part of the way into a day.

**English**

```
Pressing the calendar’s previous or next arrow several times quickly now moves one period per press and lines the days up.
```
