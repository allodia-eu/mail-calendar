# Opening a folder while mail is updating

Platforms: all
Bump: patch

> Snapshot rebuilds run concurrently and finish in any order. One begun for the folder being left
> (a sync's, after a draft was saved for instance) could finish after the folder just opened and
> publish the old folder over it. A rebuild is now dropped when the selection or the view mode it
> was built for is no longer the one showing.

**English**

```
Opening a folder while your mail is updating no longer sends you back to the folder you just left.
```

