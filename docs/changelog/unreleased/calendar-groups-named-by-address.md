# Calendar groups named by address

Platforms: macos, ios, android
Bump: patch

> The calendar manager, the calendar picker and the default-calendar setting headed each account's
> calendars with its internal id (`address@provider-host`). Every calendar row now carries the
> account's address, and every client heads its groups with it; Linux and Windows already showed
> the address, through the account switcher's list, which accounts without mail are no longer in.

**English**

```
Calendars are grouped under each account's email address instead of an internal name.
```
