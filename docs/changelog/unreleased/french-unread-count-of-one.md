# A French folder badge of one reads as one

Platforms: all
Bump: patch

> `a11y_unread_count` is the folder pane's unread badge, and it was the ninth key of the shape the
> catalog's plural forms were built for. The eight paired then did not include it, so a folder
> holding a single unread message announced "1 non lus". French is the only shipped language whose
> wording here agrees with the number; the other six word the badge without agreement, so their
> singular is the same sentence and is written as such. The badge is spoken rather than drawn (the
> number alone is what the eye sees), so this reaches a screen reader and nothing else.

```
A folder holding one unread message now reads as a singular in French.
```
