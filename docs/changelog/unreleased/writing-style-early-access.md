# Writing style and drafted replies, as early access

Platforms: all
Bump: minor

> Settings → Writing style learns a style from the person's own sent mail, and Draft a reply in
> the composer drafts in it, through an own AI endpoint or Allodia's relay, every request behind
> the jurisdiction gate (docs/ai.md). A production build offers it only while the Allodia
> entitlement carries `ai`, so the note says early access and names the account; the capability
> matrix marks the row 🚧 on every client. Privacy policy 3.0.

```
Early access, for Allodia accounts that include it: the app can learn your writing style from mail you have sent and draft a reply in it, which you edit and send yourself.
```
