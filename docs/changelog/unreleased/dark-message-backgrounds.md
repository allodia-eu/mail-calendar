# Messages follow a dark app

Platforms: macos, ios, android
Bump: minor

> The core moves a message's colours by lightness and keeps their hue, leaving pictures as sent
> (docs/reading-dark-mode.md). The sun/moon button and Settings → Reading set one persisted
> preference, as Outlook does. Each client adds its platform to this fragment as it ships.

**English**

```
In a dark app, messages are now shown on a dark background with their colours adjusted to suit; the sun and moon button above a message switches every message back to its light background, and the same switch is in Settings → Reading.
```

**Nederlands**

```
In een donkere app worden berichten nu op een donkere achtergrond getoond, met hun kleuren daarop aangepast; de zon- en maanknop boven een bericht zet alle berichten terug naar hun lichte achtergrond, en dezelfde schakelaar staat in Instellingen → Lezen.
```
