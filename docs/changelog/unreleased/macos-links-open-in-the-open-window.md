# Mail links and shares open in the window already open

Platforms: macos
Bump: patch

> Every mail link clicked elsewhere, and every file shared to the app, opened a second main window
> on top of the first. They now open their composer in the window already on screen.

**English**

```
A mail link or a shared file now opens its message in the window you already have open, rather than in a new one.
```

```

```
