# The Windows calendar's header names the week after the month

Platforms: windows
Bump: patch

> Paging the month and then choosing a week, work week or day from the view menu left the month's
> name in the header whenever the grid returned to the days it last showed: "July 2026" over a
> week in November.

**English**

```
After paging the month view, switching to a week or day view shows that period's name in the header again.
```
