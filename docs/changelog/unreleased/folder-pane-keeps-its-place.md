# The folder pane keeps its place on Windows

Platforms: windows
Bump: patch

> Every change to an unread count took each account's rows out of the pane and put them back
> collapsed, so a pane scrolled below an open subfolder moved by a few rows a moment later.

**English**

```
The folder pane no longer shifts when an unread count changes, such as after moving a message to a folder.
```

**Nederlands**

```
Het mappenpaneel verschuift niet meer wanneer een aantal ongelezen berichten verandert, bijvoorbeeld na het verplaatsen van een bericht naar een map.
```

**Deutsch**

```

```

**Français**
