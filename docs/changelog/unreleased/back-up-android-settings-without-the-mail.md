# Back up Android settings without the mail

Platforms: android
Bump: patch

> Auto Backup takes nothing from an app whose data passes 25 MB, and the mail store did so with any
> real mailbox. `data_extraction_rules.xml` now leaves the store out of cloud backup and device
> transfer, so the rest of the app's data fits again.

**English**

```
The app's settings are included in your device backup again: downloaded mail made the app too large for Android's backup, so it is now left out and downloaded again from your mail server after a restore.
```

