# A personal Microsoft or Google account no longer offers colleagues on Linux

Platforms: linux
Bump: patch

> A personal account has no organisation directory: on Microsoft, Settings → Accounts showed
> "Colleagues: needs permission" that no sign-in could fix, and on Gmail a Colleagues switch that
> found nobody. Whether an account is personal is now asked of the provider and stored with it,
> and a personal account offers no colleagues.

**English**

```
A personal Microsoft or Google account no longer offers Colleagues in Settings → Accounts, since it has no organisation directory.
```
