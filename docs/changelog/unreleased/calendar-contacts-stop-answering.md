# A calendar or address book that stops answering says so without a restart

Platforms: all
Bump: patch

> Only a dial recorded a calendar or address book that could not be reached, so one that
> connected and then stopped answering said nothing until the next launch, and stayed writable.
> Two refreshes in a row that reach nothing now raise the same notice and hold its changes; the
> next refresh that reaches it takes both away.

**English**

```
A calendar or address book that stops answering now says so after two refreshes, and takes no changes until it answers again.
```
