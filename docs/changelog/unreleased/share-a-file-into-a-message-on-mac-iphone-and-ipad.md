# Share a file into a message on Mac, iPhone and iPad

Platforms: macos, ios
Bump: minor

> The Apple clients now ship a Share Extension, so the OS offers Allodia Mail & Calendar wherever
> something can be shared: a photograph, a document, a web link, a selection. The extension draws
> nothing and holds no core; it copies the shared bytes into a drop box and asks for the app, which
> hands them to `prefill_from_share` and opens a composer already holding them. Windows, Android
> and Linux have had the surface since the core half landed. On macOS the extension is switched on
> in System Settings, as every third-party sharing extension is.

Send a file by email straight from the app you are in: share a photo, a document or a link, and a message opens with it already attached.
