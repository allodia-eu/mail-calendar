# A Thunderbird quote wraps in the reading pane

Platforms: all
Bump: patch

> Thunderbird quotes a plain-text message as `<pre wrap>`. The sanitiser dropped `wrap`, so the
> quote's long lines ran off the pane's right edge; it now keeps the attribute, and the base sheet
> lays a `pre[wrap]` out with `white-space: pre-wrap`, as Gecko does. A plain `<pre>` is unchanged.

**English**

```
Quoted text in messages from Thunderbird now wraps to the width of the reading pane instead of running off its edge.
```
