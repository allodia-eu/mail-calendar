# A reopened draft keeps its signature

Platforms: all
Bump: patch

> Opening a draft again on Windows, or changing its sender on any platform, removed the signature
> it was written with, and the next save stored the draft without it. A reopened draft now keeps
> its signature, and a reopened reply opens as a reply with both quote styles available.

**English**

```
A draft you open again keeps its signature, also when you change the sender, and a reopened reply can switch quote style.
```
