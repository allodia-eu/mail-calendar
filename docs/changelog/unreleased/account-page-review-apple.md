# Review on an account's page opens the question

Platforms: macos, ios
Bump: patch

> On an account's page in Settings, the Review under a calendar or address book paused for a server
> on another site did nothing: the question it opens was attached only to the outage banner. It now
> opens there too.

**English**

```
Review on an account’s page in Settings now opens the question about a calendar’s new server.
```
