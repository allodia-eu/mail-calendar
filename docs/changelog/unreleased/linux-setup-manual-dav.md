# Set up a calendar and contacts server by hand on Linux

Platforms: linux
Bump: minor

> The manual form takes an address book beside the mail server, and gains a "Calendar and
> contacts" type for a CalDAV or CardDAV server without mail. A calendar or address-book server
> whose certificate does not verify is shown for acceptance, as a mail server's is.

```
On Linux, the manual setup form adds an address book field and a type for calendar and contacts servers without mail.
```
