# Link a new account to another while setting it up on Linux

Platforms: linux
Bump: minor

> When another account can fill what a new IMAP or calendar account lacks, setup offers it as a last, skippable
> step: a calendar or address book from another account, or for a calendar without mail, the
> account that sends its invitations. A suggested account starts picked, and "Add another account"
> sets one up and comes back to the step.

**English**

```
On Linux, setting up an IMAP or CalDAV account offers to use another account's calendar or contacts with it.
```
