# Settings on Linux closes with its close button alone

Platforms: linux
Bump: patch

> The Settings window had a Done button beside the title bar's close button, two controls for one
> thing, since every change there applies as it is made. Only the close button remains.

The Settings window on Linux has one close button instead of a Done button beside it.
