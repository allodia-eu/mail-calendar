# Shared mailboxes follow the page's other controls

Platforms: all
Bump: patch

> Switching a shared mailbox and adding one by its address show a spinner while they run and hold
> the page, and an address nothing answered to stays in its field to be corrected.

**English**

```
In Settings, switching a shared mailbox or adding one now shows that it is working, and an address that wasn't found stays to be corrected.
```

**Nederlands**

```
In Instellingen laat het aan- of uitzetten of toevoegen van een gedeelde mailbox nu zien dat het bezig is, en een adres dat niet gevonden werd blijft staan om te verbeteren.
```

**Deutsch**

```
In den Einstellungen zeigt das Ein- oder Ausschalten oder Hinzufügen eines geteilten Postfachs jetzt, dass es läuft, und eine nicht gefundene Adresse bleibt zum Korrigieren stehen.
```

**Français**

```
Dans les Réglages, activer, désactiver ou ajouter une boîte aux lettres partagée indique désormais que c’est en cours, et une adresse introuvable reste affichée pour être corrigée.
```

**Español**

```
En Ajustes, activar, desactivar o añadir un buzón compartido ahora muestra que está en curso, y una dirección que no se encontró se mantiene para corregirla.
```

**Italiano**

```

```

**Português**
