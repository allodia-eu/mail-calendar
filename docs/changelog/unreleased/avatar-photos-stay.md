# Sender photos no longer flash to initials

Platforms: macos, ios, android, windows, linux
Bump: patch

**English**

```
Sender photos in the message list no longer flash to initials and back when a draft is saved or contacts sync.
```

**Nederlands**

```
Afzenderfoto's in de berichtenlijst springen niet meer even naar initialen wanneer een concept wordt opgeslagen of contacten synchroniseren.
```

