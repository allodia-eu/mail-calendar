# An account's Sign-in section follows the page's other controls

Platforms: all
Bump: patch

> The section is decided by the core on every platform, so each one offers the same ways in for
> the same account. A password or API token the server stopped accepting is typed again in the
> Sign-in section, including on a JMAP account not used for mail, and a password being tried shows
> that it is working until the server has answered.

**English**

```
In Settings, an account's Sign-in section is where a refused password is entered again, and it shows that a new password is being tried until the server answers.
```

**Nederlands**

```
In Instellingen voer je een geweigerd wachtwoord opnieuw in bij Aanmelding van het account, en daar zie je dat een nieuw wachtwoord wordt geprobeerd tot de server antwoordt.
```
