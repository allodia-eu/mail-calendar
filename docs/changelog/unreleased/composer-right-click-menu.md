# A right-click menu while you write

Platforms: android, linux
Bump: minor

> Each host filters its WebView's own menu rather than drawing one, so every surviving item keeps
> the platform's label, keyboard equivalent and behaviour. What is removed is what a composer must
> not offer: opening a link (navigation is blocked, so the item did nothing), downloading one,
> reloading the document, and the web inspector.

**English**

```
Right-click while writing a message to cut, copy and paste, and to copy the address of a link in
the message you are replying to.
```

**Nederlands**

```
Klik met rechts terwijl je schrijft om te knippen, kopiëren en plakken, en om het adres te
kopiëren van een link in het bericht dat je beantwoordt.
```
