# A folder inside a folder is drawn inside it

Platforms: all
Bump: minor

> The pane drew every folder at one level, however the server nested them. That was legible only
> because two of the four transports named a folder by its whole path; now that every adapter
> reports the folder's own name and its parent, a flat list would put two rows called `2024` in
> one pane with nothing saying which Archive each is in. Each folder holding folders now carries
> its own disclosure control, remembered per account and folder across launches, and a folder
> nobody has touched shows what is inside it, so nothing that was on screen before goes missing.
> A role-bearing folder stays at the top whatever the server says, which is what keeps Sent and
> Trash out of Gmail's `[Gmail]` container.
