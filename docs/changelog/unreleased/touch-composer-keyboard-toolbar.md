# The iPhone and iPad composer keeps its formatting toolbar on the keyboard

Platforms: ios
Bump: minor

> The header and the files are drawn inside the editor's own page, which is the composer's one
> scroll; the toolbar rides on the keyboard (`useNativeComposerChrome`), and WebKit's form bar over
> the message is gone (`docs/composer-layout.md`, rule 7).

**English**

```
On iPhone and iPad the formatting toolbar sits on the keyboard, and the message runs the full width of the screen.
```
