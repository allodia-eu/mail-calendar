# Find a calendar server again when the provider moves it

Platforms: all
Bump: patch

> A server found through DNS is often one machine's name, which a provider may change. The app
> kept it forever; it now looks again when it stops answering and follows a move within the same
> provider, never anywhere else.

**English**

```
When a calendar or address-book server stops answering, the app looks it up again and moves to the new address if your provider moved it.
```
