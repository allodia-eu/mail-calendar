# The manual form shows the ports it dials

Platforms: windows
Bump: patch

> Two faults in the manual form's Port fields. Reopening account setup kept the previous
> account's detected ports on screen while the form dialled the standard ones. And the port
> followed the security picker only once: the form's own write came back as TextChanged after
> it had returned and was taken for the person typing a port.

**English**

```
On the manual setup form, the port follows the security you choose again, and adding another account no longer shows the previous account's ports.
```

```
Op het handmatige instelformulier volgt de poort weer de beveiliging die je kiest, en bij het toevoegen van nog een account staan de poorten van het vorige account er niet meer.
```
