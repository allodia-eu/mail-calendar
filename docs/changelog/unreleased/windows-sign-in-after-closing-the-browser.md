# Signing in again after closing the browser on Windows

Platforms: windows
Bump: patch

> Closing the browser during a sign-in in setup sends nothing back, and the sign-in button stayed
> disabled until the five-minute cap ran out. A press now starts over, and a sign-in that was
> cancelled no longer opens the browser or adds the account afterwards.

**English**

```
If you close the browser during a sign-in while adding an account, you can now press the sign-in button again straight away, and a cancelled sign-in no longer opens the browser or adds the account afterwards.
```
