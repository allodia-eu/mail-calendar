# Images over plain http load

Platforms: macos, ios, android
Bump: patch

> A message whose images are linked over plain `http://`, common in signatures, kept showing broken
> images after "Load images", because the platform's cleartext policy refused the load before the
> message's own policy was asked. Those images now load once the reader chooses to load images.

**English**

```
Images linked over plain http, common in email signatures, now load when you choose to load a message's images.
```
