# Signatures are saved by the core, once, and take the pictures every mail app shows

Platforms: all
Bump: patch

> Settings → Signatures is drawn from one core record. Save and Delete run off the UI thread
> with a spinner until the library is written, and a double press on Save no longer creates two
> signatures. The name and picture rules are the core's: PNG, JPEG or GIF up to 512 KB, so Android
> and Apple no longer accept SVG or HEIC files, and the file pickers offer only those three. A
> library that could not be written raises the failed-save notice instead of being dropped.
