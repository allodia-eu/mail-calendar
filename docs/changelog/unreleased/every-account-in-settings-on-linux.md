# Every account in Settings on Linux

Platforms: linux
Bump: minor

> Settings → Accounts listed mail accounts only, each as one card. It now lists every account and
> opens a page per account with its uses, links, mail settings and removal.

**English**

```
Settings → Accounts lists every account; open one to choose whether it is used for mail, calendar and contacts, link it to another account, or remove it.
```

**Nederlands**

```
Instellingen → Accounts toont elk account; open er een om te kiezen of het voor e-mail, agenda en contacten wordt gebruikt, het aan een ander account te koppelen of het te verwijderen.
```

**Deutsch**

