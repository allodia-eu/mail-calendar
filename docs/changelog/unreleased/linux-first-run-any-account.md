# Open the app normally on Linux when the only account is a calendar

Platforms: linux
Bump: patch

> First-run setup was decided from the mail accounts alone, so a device whose only account was a
> calendar and contacts one opened on setup every time. Removing the last account now returns to
> it.

**English**

```
On Linux, the app no longer opens on account setup when your only account is used for a calendar and contacts, and removing your last account takes you back to setup.
```

**Nederlands**

```

```
