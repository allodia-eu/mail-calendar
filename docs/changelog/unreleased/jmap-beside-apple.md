# The calendar found beside a JMAP server, offered after setup on macOS, iPhone and iPad

Platforms: macos, ios
Bump: minor

> When detection finds a calendar or address-book server beside a JMAP server whose session has
> none, the link step of the account set up from it offers that server as an account of its own,
> for only what the session lacks (`dav_setup_beside`); a Nextcloud server's card leads with its
> own sign-in. A server without a calendar or contacts now gets the link step even with nothing
> to pick.

**English**

```
When your mail server has no calendar or address book of its own but one was found beside it, setup now offers to add it as well.
```
