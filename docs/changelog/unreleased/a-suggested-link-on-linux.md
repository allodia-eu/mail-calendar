# A suggested link on Linux

Platforms: linux
Bump: minor

> An account's page in Settings → Accounts offered every calendar a mail account could link to
> with nothing to tell the likely one apart. It now names the one whose server schedules as the
> mail account's address, with a button that links it.

**English**

```
An account's page in Settings → Accounts suggests the calendar that belongs to the same address, and links it with one click.
```
