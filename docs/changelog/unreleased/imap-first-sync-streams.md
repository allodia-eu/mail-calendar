# A new IMAP account's mail appears as it downloads

Platforms: all
Bump: patch

> The wrapper that redials a dropped IMAP connection collected a whole folder pass before passing
> any of it on, so a large inbox stayed empty until its last message had arrived: about 20 seconds
> on a Yahoo inbox of 1,500 messages. Each batch now shows as it arrives.

**English**

```
When you add an IMAP account, its messages now appear as they download instead of all at once at the end.
```
