# Spaces and tabs reach recipients as typed

Platforms: all
Bump: patch

> The outgoing HTML wrote spaces verbatim, so a recipient's client collapsed a run of them into one
> and dropped any at the start or end of a line, and a tab became a space. They are now written so
> that none collapses, and a reopened draft keeps them too.

```
Extra spaces, indentation and tabs in a message now reach recipients as you typed them.
```
