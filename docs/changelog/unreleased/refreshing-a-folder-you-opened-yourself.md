# Refreshing a folder you opened yourself

Platforms: all
Bump: patch

> An account binds a provider to INBOX and to the folders the server tagged with SPECIAL-USE;
> every other folder is downloaded once, when it is opened, and was then in no account pass and
> under no IDLE watch. Standing in one, a pull, a poll tick and a return to network all
> republished the rows already on screen, and restarting the app was the only way to see new
> mail in it. A pass now re-syncs the folder on screen when it is one the account binds no
> provider to. Separately, the body-warm pass is what gives a row its preview snippet on a
> provider that sends none (IMAP: the snippet is derived from the body): it wrote the snippets to
> the store and stopped there, so the rows kept the blank second line they were published with
> until something else happened to rebuild the list. It now rebuilds once at the end of a pass
> that warmed anything.

```
Mail arriving in a folder you opened yourself now shows up on a refresh, and message previews appear as soon as the bodies are downloaded.
```
