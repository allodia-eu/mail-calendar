# The iPhone reading view without the tab bar

Platforms: ios
Bump: patch

> The tab bar is hidden on the pushed reading view only; Back returns to the list and the tabs.
> Contact details keep it.

**English**

```
On iPhone, an open message now has the whole screen: the Mail, Calendar and Contacts tabs return when you go back to the list.
```
