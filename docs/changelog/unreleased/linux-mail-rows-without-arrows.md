# Linux mail rows lead with a conversation's chevron, and their avatars line up

Platforms: linux
Bump: patch

> A conversation's chevron moves from the end of its row to the start, ahead of the unread dot and
> the avatar, as on macOS and Windows, pointing right while closed. No row ends in an arrow, the
> avatar is the row's action, and every row keeps the chevron's column, so dots, avatars and
> subjects stand in one column down the list.

**English**

```
In the message list a conversation's chevron now sits at the start of its row, rows no longer end in an arrow, and every sender's picture lines up down the list.
```
