# Linux mail rows draw no arrow, and their avatars line up

Platforms: linux
Bump: patch

> A message or conversation row no longer ends in an arrow; its avatar is the row's action, and every
> row leads with the unread dot then the avatar, so conversation avatars no longer stand a few pixels
> off the others.

```
In the message list, rows no longer end in an arrow, and every sender's picture now lines up down the list.
```
