# Offer Fastmail sign-in again

Platforms: all
Bump: patch

> The sign-in check stopped at the redirect Fastmail answers its session address with, so the
> setup card fell back to the app-password field.

**English**

```
Adding a Fastmail account offers to sign in with Fastmail again, instead of asking for an app password.
```

**Nederlands**

```
Bij het toevoegen van een Fastmail-account kun je weer inloggen bij Fastmail, in plaats van een app-wachtwoord in te voeren.
```

**Deutsch**

```

```

**Français**


**Español**
