# A calendar or address book server that moves is followed, and one on another site is asked about first

Platforms: all
Bump: minor

> Calendar and contacts connects now start where the server last said the account lives, and
> look the servers up again only when the server says that is gone, never because a network
> was slow or offline. A server found on another site pauses that calendar or address book
> and asks the person whether the move is expected, since a changed DNS record looks the same
> as a provider moving.

**English**

```
When your calendar or address book server moves, the app follows it, and if the new server is run by someone else it asks you first instead of sending your password there.
```
