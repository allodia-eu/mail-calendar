# On Windows, the language chosen in Settings reaches the controls Windows draws for the app

Platforms: windows
Bump: patch

> The language picker set the app's own strings only, so the navigation pane's Settings item and
> the spoken names of a notice's icons stayed in the system's display language. The choice is now
> the Windows App SDK's language override as well.

**English**

```
On Windows, the language chosen in Settings now also applies to the few labels that followed the system language, including those a screen reader reads.
```
