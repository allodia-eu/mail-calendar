# A draft in a conversation says it is a draft

Platforms: all
Bump: patch

> A draft inside a conversation carried the "Sent" badge, because it is written from the account's
> own address, and a draft another client stored without a sender was labelled "(no subject)". It
> is now badged "Draft", and opening a conversation in Drafts opens its latest draft for editing on
> every platform.

**English**

```
In a conversation, a draft is now marked Draft instead of Sent, and opening a conversation in Drafts opens its latest draft for editing.
```
