# Links in messages and events

Platforms: all
Bump: minor

> Two halves. Writing: a Link button (and Ctrl/Cmd+K) in the shared editor makes, changes and
> removes a link, and an address typed into the body becomes one when the word ends with a space
> or Enter. The target is `http`, `https` or `mailto` only and is checked again in Rust on submit;
> the plain-text part carries `words <address>`. Reading: web and mail addresses written as text
> become links in HTML bodies (a pass over the sanitiser's output in the core), in plain-text
> bodies, in event notes and in an invitation's description (native text built from the core's
> runs). Every link opens through `should_open_external_link`. Bare domains and bare email
> addresses are not linked.

**English**

```
Add links to a message with the new Link button, or type an address and press Space. Web addresses in messages and event notes are now clickable.
```
