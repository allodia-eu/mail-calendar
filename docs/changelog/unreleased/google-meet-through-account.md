# Google Meet through a Google account

Platforms: all
Bump: minor

> A Google account gains the Video meetings use, as a Microsoft work account has for Teams. It
> asks for one more Google permission, which reaches only the meetings this app makes, so an
> account added earlier is asked to sign in again when the use is switched on.

**English**

```
Add a Google Meet meeting to an event on any calendar through your Google account, once Video meetings is on for it in Settings.
```

**Nederlands**

```
Voeg via je Google-account een Google Meet-vergadering toe aan een afspraak in elke agenda, zodra Videovergaderingen daarvoor aanstaan in Instellingen.
```

**Deutsch**

```
Fügen Sie über Ihr Google-Konto einem Termin in jedem Kalender eine Google Meet-Besprechung hinzu, sobald Videobesprechungen dafür in den Einstellungen aktiviert sind.
```

**Français**

```
Ajoutez une réunion Google Meet à un événement de n’importe quel calendrier avec votre compte Google, une fois les Réunions vidéo activées pour ce compte dans Réglages.
```

**Español**

```
Añade una reunión de Google Meet a un evento de cualquier calendario con tu cuenta de Google, una vez activadas las Reuniones de vídeo para ella en Ajustes.
```

**Italiano**

```
Aggiungi una riunione Google Meet a un evento di qualsiasi calendario con il tuo account Google, una volta attivate le Riunioni video per l’account in Impostazioni.
```

**Português**

```
Adicione uma reunião do Google Meet a um evento de qualquer calendário com a sua conta Google, depois de ativar as Reuniões de vídeo para ela em Definições.
```
