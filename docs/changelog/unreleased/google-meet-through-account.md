# Google Meet through a Google account

Platforms: all
Bump: minor

> A Google account gains the Video meetings use, as a Microsoft work account has for Teams. It
> asks for one more Google permission, which reaches only the meetings this app makes, so an
> account added earlier is asked to sign in again when the use is switched on.

**English**

```
Add a Google Meet meeting to an event on any calendar through your Google account. Switch on Video meetings on the account’s page in Settings.
```

**Nederlands**

```
Voeg via je Google-account een Google Meet-vergadering toe aan een afspraak in elke agenda. Zet Videovergaderingen aan op de pagina van het account in Instellingen.
```

**Deutsch**

```
Fügen Sie über Ihr Google-Konto einem Termin in jedem Kalender eine Google Meet-Besprechung hinzu. Aktivieren Sie Videobesprechungen auf der Seite des Kontos in den Einstellungen.
```
