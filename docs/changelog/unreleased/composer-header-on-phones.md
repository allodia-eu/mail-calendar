# The composer's header fits a phone

Platforms: ios
Bump: patch

> With two accounts and a signature, the header was wider than an iPhone: "From" was squeezed to a
> letter a line and every button's title wrapped. The bar now follows Apple's guidelines.

**English**

```
The composer fits iPhone and iPad again: Attach and Signature are symbols, Save as draft and Discard sit behind More, Close is ✕ and Send stands out.
```
