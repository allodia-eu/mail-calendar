# Name a calendar-only account by its address on Linux

Platforms: linux
Bump: patch

> The event editor's calendar picker and Settings → Calendar's default-calendar headings looked an
> account's address up in the mail accounts, so an account used only for its calendar (a Nextcloud
> sign-in) was named by its internal id. Both now use the address the core gives every calendar.

**English**

```
Calendars of an account used only for its calendar, such as a Nextcloud account, are named by its address rather than an internal name.
```
