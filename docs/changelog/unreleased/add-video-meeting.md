# Add a video meeting to an event

Platforms: all
Bump: minor

> The editor gains a Video meeting row, filled by the core per calendar: the meeting the calendar's
> own server makes (Teams on Microsoft, Meet on Google), then Jitsi Meet once a server is set in
> Settings → Videoconferencing, which is empty until the person fills it. A Jitsi room's name is
> 128 secure random bits and making it sends nothing. An edit replaces the meeting or takes it off.

**English**

```
Add a video meeting to an event as you create or edit it: Teams or Google Meet on their own calendars, or Jitsi Meet on your own server, set in Settings.
```
