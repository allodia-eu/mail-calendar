# A composer nobody wrote in is no longer saved to Drafts

Platforms: all
Bump: patch

> The autosave measures edits against the editor's change count as the opening seeds left it,
> read in the batch that snapshots the seeded document. Apple read it as the view appeared, before
> the seeds, so a blank New Message was stored as an empty draft and a reopened Thunderbird or
> Outlook draft was saved over in this app's markup; Android and Linux took it on the first sample,
> which missed a short reply typed before it and, on a slow load, could count the seeds. Windows
> counted the Subject's own opening value, which WinUI reports a turn later, as an edit.

**English**

```
A message you open and leave untouched, including a reply or a draft from another app, is no longer saved to Drafts on its own.
```
