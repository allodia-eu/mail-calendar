# The composer in the main window can be popped out into a window of its own

Platforms: macos, windows, linux
Bump: minor

> A new message, reply or forward written beside the mailbox moves into a window holding
> everything written so far, on the same draft (docs/reading-window.md, "Popping a composer
> out").

**English**

```
A message you are writing beside the mailbox can now be moved into a window of its own, with everything you have written so far.
```

**Nederlands**

```
Een bericht dat je naast de mailbox schrijft, kun je nu naar een eigen venster verplaatsen, met alles wat je al hebt geschreven.
```

