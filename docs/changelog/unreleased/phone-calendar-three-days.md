# A phone opens the calendar on three days

Platforms: ios, android
Bump: patch

> Decided in the core from the device class every client already reports, so no client changed.
> Only a shape the user chose is persisted, so an install that already has one keeps it, and the
> default never hardens into a choice nobody made. A phone that never chose a shape, new or
> upgraded, opens on three days.

On a phone, the calendar now opens on three days until you choose another view.
