# The calendar no longer redraws itself when nothing in it has changed

Platforms: linux
Bump: patch

> The agenda, the month and the day and week grid were rebuilt on every input the app received,
> a time-zone check once a minute included, so a press on an event could be lost and keyboard
> focus on a row went with it.

**English**

```
Clicking an event in the calendar now always opens it, and the calendar keeps your keyboard place.
```

