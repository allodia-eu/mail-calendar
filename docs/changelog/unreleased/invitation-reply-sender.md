# Answering an invitation answers as you, not as another attendee

Platforms: all
Bump: patch

> An invitation addressed to several attendees, as Exchange sends one, was sometimes answered as the
> first of them rather than as you, so the reply stayed in the Outbox when the mail server refused
> that sender. The answer now goes out from your own address, or from the alias the invitation was
> delivered to.

**English**

```
Answering a meeting invitation addressed to several people now replies from your own address, so the answer no longer stays in the Outbox.
```

