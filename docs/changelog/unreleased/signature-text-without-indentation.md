# A signature's and a quote's plain text follow what their HTML shows

Platforms: all
Bump: patch

> The text half of a quote or signature is derived from its HTML in the editor, which collapsed
> spaces and tabs but kept the markup's own line breaks, so a Thunderbird signature reopened from
> Drafts went out with its HTML indentation as extra lines and leading spaces.

**English**

```
The plain-text version of a signature or quote from a draft written in another app no longer picks up stray line breaks and spaces.
```
