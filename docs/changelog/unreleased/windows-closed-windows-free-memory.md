# Closed windows free their memory on Windows

Platforms: windows
Bump: patch

> A closed reading or composer window stayed in memory, with its message view or composer, until
> the app quit: a few megabytes per window opened.

**English**

```
Message and draft windows give their memory back when you close them.
```
