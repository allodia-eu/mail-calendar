# The desktop formatting toolbar keeps to one row

Platforms: macos, windows, linux
Bump: minor

> On a desktop the editor's toolbar keeps to one row and moves the controls that do not fit behind
> More at its end; the composer's header scrolls away before the message does
> (`docs/composer-layout.md`, rules 2 and 7).

**English**

```
The formatting toolbar keeps to one row, with anything that does not fit behind its ⋯ button, and the message no longer sits in a box of its own.
```
