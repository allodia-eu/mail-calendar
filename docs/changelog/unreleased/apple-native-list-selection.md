# Selecting messages the way the platform does on Mac, iPhone and iPad

Platforms: macos, ios
Bump: minor

> The Apple message list now uses the list control's own selection. On the Mac that brings ⌘A,
> Edit ▸ Select All, Edit ▸ Delete and the arrow keys; on iPhone and iPad, Select puts the list
> in edit mode with the system's checkmarks, and ⌘A on a hardware keyboard selects every row.

**English**

```
On Mac, ⌘A and Edit ▸ Select All now select every message in the list, and the arrow keys move through it. On iPhone and iPad, Select shows checkmarks and ⌘A on a keyboard selects every message.
```

