# Undo and redo while writing, with a keyboard on Android

Platforms: android
Bump: minor

> The body's history is the shared bundle's (`history.ts`), and the recipient fields keep a step
> per address (`RecipientHistory`), so a removed recipient can be undone.

**English**

```
With a keyboard attached, Ctrl+Z now takes back the newest change in the message or the field you are in, Ctrl+Shift+Z or Ctrl+Y puts it back, and a removed recipient comes back whole.
```

