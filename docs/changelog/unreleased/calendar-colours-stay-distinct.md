# Every calendar has a colour of its own

Platforms: all
Bump: patch

> iCloud sends a calendar's colour with an alpha channel (`#RRGGBBAA`), which was not read, so every
> iCloud calendar fell back to the same blue. Yahoo names one colour for all of an account's
> calendars, and two accounts can name the same one. A server's colour is now kept only while no
> earlier calendar holds its palette hue; the rest take a hue nobody holds, across accounts.

```
Each calendar now has a colour of its own, across all your accounts, including iCloud and Yahoo calendars that all showed the same colour.
```
