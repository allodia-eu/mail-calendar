# The 12/24-hour clock reaches mail

Platforms: macos, ios, windows, linux
Bump: patch

> Android already threaded the setting into its mail formatters; the other three formatted mail
> times on a fixed 24-hour clock while their calendars followed the setting. Each now draws a mail
> time with the pattern its own calendar uses, and the agenda lists on Apple and Windows, which
> borrowed the mail formatter, follow it too.

**English**

```
Times in the message list, the message header and the quoted text of a reply now follow the 12/24-hour setting, as the calendar already did.
```
