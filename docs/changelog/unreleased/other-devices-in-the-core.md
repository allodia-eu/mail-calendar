# Syncing accounts with your other devices is run by the core

Platforms: all
Bump: patch

> The core runs the pass over the person's other devices itself and keeps what it found, so a
> question about an account removed here goes with it and nothing from a signed-out account stays
> on screen. Changing how an account is synced shows that it is working, says when it did not take,
> and is offered for every account the other devices can hold, not only those used for mail.

**English**

```
Changing how an account is synced with your other devices now shows that it is working and says when it didn’t take.
```
