# Settings → Accounts keeps its place on Linux

Platforms: linux
Bump: patch

> A change on an account's page scrolled it back to the top, and a suggested link that arrived
> after the page was drawn only appeared after the next change. The page now keeps its scroll
> position and shows what the server answers when it arrives, unless a field is being typed in.

**English**

```
Settings → Accounts keeps its scroll position after a change, and shows a suggested link as soon as the server names it.
```
