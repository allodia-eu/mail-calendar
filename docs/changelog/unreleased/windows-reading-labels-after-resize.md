# On Windows, the buttons above a message keep their labels after the window is maximised

Platforms: windows
Bump: patch

> The row learnt the width its labels need from itself while stretched to the pane, so it learnt
> the pane's width: a wider pane dropped the labels, and no width afterwards brought them back
> until the app was restarted.

**English**

```
On Windows, the Reply, Forward, Archive and Delete buttons above a message keep their labels after the window is maximised or resized.
```
