# Calendar and video meeting settings keep up with the calendars

Platforms: macos, ios, android, windows, linux
Bump: patch

> Settings → Calendar's default calendar and Settings → Videoconferencing are drawn from the
> core's records and follow its calendar signals, so they no longer show the calendars as they
> were when Settings opened (Linux, Windows). Every calendar picker names an account only while
> there are two or more.

**English**

```
The default calendar and video meeting settings now keep up as calendars arrive or change, and a calendar list with one account no longer repeats its address.
```
