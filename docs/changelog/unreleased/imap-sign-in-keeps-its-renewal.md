# An IMAP sign-in keeps its renewal

Platforms: all
Bump: patch

> An IMAP account connected by signing in with its provider now saves the sign-in its server
> renews, so it no longer asks to be signed in again after the app restarts.

**English**

```
An email account connected by signing in with your provider no longer asks you to sign in again after the app restarts.
```
