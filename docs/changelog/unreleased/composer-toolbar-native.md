# A flat formatting toolbar that follows a dark appearance

Platforms: all
Bump: patch

> The shared editor bundle draws its toolbar and panels as a command bar (borderless controls,
> pickers with a chevron, icons for the two list buttons) in the scheme each host names through
> `setComposerScheme`, so an explicit Light or Dark in Settings is followed on every platform, and
> keeps the page light in both schemes so a colour picked there is the colour sent.

**English**

```
The formatting toolbar above a message you are writing is plainer, with icons for lists, and turns dark in a dark appearance; the message itself stays white, as its recipient will see it.
```

