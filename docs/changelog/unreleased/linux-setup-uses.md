# Choose mail, calendar and contacts when setting an account up on Linux

Platforms: linux
Bump: minor

> The found card offers mail, calendar and contacts as separate choices, each on where its server
> was found, and an address with a calendar and address book but no mail server is set up for
> those alone. The password stays behind "Use a password instead" where the provider offers a
> sign-in, and Back keeps the address typed.

**English**

```
When you add an account on Linux, you choose whether it is used for mail, calendar and contacts, so an account can also hold just a calendar and contacts.
```
