# A Try again that does not get through says so

Platforms: macos, ios, windows, android, linux
Bump: patch

> The client cannot tell when the dial a Try again starts has ended, so the core judges it: the
> notice says the remedy did not work when that dial ends and the server still cannot be reached.

**English**

```
When Try again on a notice still cannot reach the server, the notice now says so.
```
