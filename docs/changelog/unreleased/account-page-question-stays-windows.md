# A question on an account's page stays open until it is answered, on Windows

Platforms: windows
Bump: patch

> Removing an account or switching one of its uses off asks first, beneath the control. The page
> is drawn again whenever the account's state changes, and that closed the question by itself,
> which happened throughout while an account was reconnecting. It now stays open until answered.

**English**

```
Confirming the removal of an account, or switching one of its uses off, no longer closes by itself while the account reconnects.
```
