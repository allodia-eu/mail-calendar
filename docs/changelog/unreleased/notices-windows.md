# Windows draws the core's notices: one bar per screen, and the account it is about

Platforms: windows
Bump: minor

> What needs attention (a sign-in that stopped working, a calendar that did not connect, being
> offline) is now one bar above the screen on show, with the rest behind "N more issues", each with
> its own button; the account it is about says so in the folder pane and on its page in Settings.

**English**

```
Anything that needs your attention now appears in one bar above the screen, with its own button, and the account it concerns says so in the folder pane.
```
