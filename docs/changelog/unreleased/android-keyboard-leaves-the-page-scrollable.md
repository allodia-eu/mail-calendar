# The keyboard no longer covers a page on Android

Platforms: android
Bump: patch

> The app is edge-to-edge, so the window kept its size under the keyboard and the controls below a
> field (Continue on Add account, the rest of the setup steps, Settings, the event editor) could
> not be reached until the keyboard was put away. The keyboard's action key on the address field
> now continues as well.

**English**

```
When the keyboard is open, account setup, Settings and the event editor now scroll to everything below the field, and the keyboard's own key continues from the email address.
```

