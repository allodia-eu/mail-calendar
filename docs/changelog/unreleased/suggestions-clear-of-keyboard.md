# Address suggestions stay clear of the keyboard on Android

Platforms: android
Bump: patch

> The list a recipient or invitee field offers is a popup, which the keyboard does not resize, so
> it is sized to the room between the field and the keyboard, opens above the field where that
> room is too small, and spans the window's width.

**English**

```
Address suggestions in To, Cc, Bcc and a meeting's invitees now stay above the keyboard, use the full width of the screen and scroll when there are many.
```
