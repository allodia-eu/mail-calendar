# Keyboard commands on the Mac, iPad and iPhone

Platforms: macos, ios
Bump: minor

**English**

```
New Mail, New Event, the calendar views, Back to Today, moving through the calendar, Manage Calendars and Sync are now in the menu bar, with keyboard shortcuts that also work on iPad and iPhone with a keyboard.
```
