# Keep a Settings field and its button above the keyboard on Android

Platforms: android
Bump: patch

> Settings drew no room for the keyboard, so a field low on a page, and the button under it, could
> not be scrolled into view while typing; the pages now make room for it.

**English**

```
On Android, a Settings field and the button below it now stay reachable above the keyboard while you type.
```
