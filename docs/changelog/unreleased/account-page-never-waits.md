# An account's page no longer holds up the window while an account reconnects

Platforms: all
Bump: patch

> Reading an account's page and the accounts list reads only what the core keeps in memory, so a
> reconnect that holds the account list no longer stops the window from responding.

Settings no longer stops responding while an account reconnects.
