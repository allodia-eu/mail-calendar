# A closed composer releases its memory

Platforms: macos, ios
Bump: patch

> Every message opened for writing left a web content process running after it closed, about
> 14 MB each in Activity Monitor, until the app quit. Closing a composer now ends it.

**English**

```
Closing a message you were writing now frees the memory it used, rather than holding it until the app quits.
```
