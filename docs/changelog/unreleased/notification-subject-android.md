# A tapped notification opens under the message's subject

Platforms: android
Bump: patch

> A tap opens the named message straight away, and when the list did not hold that message yet the
> reading header had no row to take its title from and showed "(no subject)" for good. The core's
> reading snapshot now carries the subject, as it already carried the sender, and the header takes
> it from there.

**English**

```
Opening a message from a notification now shows its subject, even before the message list has loaded.
```
