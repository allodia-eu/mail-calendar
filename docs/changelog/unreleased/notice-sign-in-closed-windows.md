# A sign-in left in the browser is no longer said to have failed, on Windows

Platforms: windows
Bump: patch

> A notice's Sign in again whose browser tab was closed reported "That didn't work" five minutes
> later, when the app stopped waiting. It now says nothing, as a cancelled sign-in does. The list
> behind "N more issues" also wraps a long sentence instead of cutting it off.

**English**

```
Closing the browser during a sign-in no longer marks the notice as failed, and longer issues are shown in full.
```
