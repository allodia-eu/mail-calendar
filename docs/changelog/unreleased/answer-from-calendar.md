# Answer a meeting from the calendar

Platforms: android, linux
Bump: minor

> The calendar's answer takes the invitation card's delivery routes, read from the stored event, so
> the organiser hears it the same way and a server that cannot deliver asks the same question. It
> is for the whole meeting, because the engine's RSVP writes an event as a whole. Apple and Windows
> follow in their own issues.

**English**

```
Accept, answer maybe to or decline a meeting from its event in the calendar, and change your answer later. The organiser is told as when you answer the invitation email.
```

**Nederlands**

```
Accepteer een vergadering, antwoord misschien of wijs haar af vanuit de afspraak in de agenda, en wijzig je antwoord later. De organisator hoort het zoals wanneer je de uitnodiging in je e-mail beantwoordt.
```

**Deutsch**

```
Nehmen Sie eine Besprechung direkt im Kalender an, antworten Sie mit Vielleicht oder lehnen Sie sie ab, und ändern Sie Ihre Antwort später. Der Organisator erfährt es wie bei einer Antwort auf die Einladungs-E-Mail.
```
