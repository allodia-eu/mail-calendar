# Choose mail, calendar and contacts when setting an account up on Windows

Platforms: windows
Bump: minor

> The found card offers mail, calendar and contacts as separate choices, each on where its server
> was found, and an address with a calendar and address book but no mail server is set up for
> those alone. The manual form gains an address book field and a "Calendar and contacts" type,
> and a Microsoft or Google sign-in asks the provider only for the uses chosen, naming any it did
> not allow on the account's page in Settings.

**English**

```
When you add an account on Windows, you choose whether it is used for mail, calendar and contacts, and a Microsoft or Google sign-in asks only for those.
```
