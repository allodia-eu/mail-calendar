# A spinner while a separate calendar server connects

Platforms: linux, windows
Bump: patch

> The form that gives a calendar and contacts a sign-in of their own only greyed its controls while
> Connect or Skip ran, which can take half a minute, so it looked as if it had hung. A spinner now
> turns beside its buttons, as it already did on macOS, iOS and Android.

**English**

```
Connecting a calendar on a separate server now shows a spinner while it works, rather than looking stuck.
```
