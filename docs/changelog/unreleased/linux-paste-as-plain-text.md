# Ctrl+Shift+V pastes plain text on Linux

Platforms: linux
Bump: minor

> With pasted text now keeping its formatting, a plain-text paste has to exist on every platform.
> WebKitGTK binds nothing to Ctrl+Shift+V, so the composer's host gives the chord WebKit's own
> PasteAsPlainText command, whose paste event carries the text flavour alone.

```
Ctrl+Shift+V pastes text into a message without its formatting.
```
