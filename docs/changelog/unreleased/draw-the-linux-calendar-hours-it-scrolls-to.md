# Draw the Linux calendar's events for the hours it scrolls to

Platforms: linux
Bump: patch

> The grid paints only the events inside its viewport, and GTK moves a scrolled child without
> redrawing it. Opening the calendar framed on the current hour therefore showed only the events of
> the hours visible at midnight, until something else caused a redraw.

The calendar on Linux now shows every event in the hours you scroll to, not only the early morning.
