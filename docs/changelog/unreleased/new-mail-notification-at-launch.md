# Mail that arrives as the app opens gets its notification

Platforms: macos, windows, linux
Bump: patch

> A desktop withholds the mail its launch sync brings in, by comparing each message's received
> time with when the session began. Both are whole seconds, and the comparison was strict, so mail
> received in the second the app opened counted as catch-up and was never announced. Found by the
> Windows notification suite on a fast host, which delivers within that second.
