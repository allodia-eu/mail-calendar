# Linux frees what a closed composer, window or signature editor held, and a new composer always draws

Platforms: linux
Bump: patch

> Every composer opened, message window closed, signature edited and message printed kept a
> process of its own running afterwards, about 180 MB each. Once enough had piled up, a new
> composer could open with an empty space where the message belongs.

**English**

```
Closing a message you were writing, a message window or the signature editor, or printing a message, now frees its memory, and a new message no longer opens without its writing area.
```
