# Adding an account that is already set up

Platforms: all
Bump: patch

> The account id is the mailbox (login and server), so a password account and a sign-in account
> for the same address collided: the second add replaced the first's credential and providers in
> place, and its calendar and contacts vanished. The add is now refused before anything changes.

**English**

```
Adding an account that is already set up now says so and leaves the existing account as it is, where it used to replace it and lose its calendar and contacts.
```

**Nederlands**

```
Een account toevoegen dat al is ingesteld, meldt dat nu en laat het bestaande account zoals het is. Voorheen werd het vervangen en raakte het zijn agenda en contacten kwijt.
```

**Deutsch**

```
Wenn Sie ein Konto hinzufügen, das bereits eingerichtet ist, wird das jetzt gemeldet und das vorhandene Konto bleibt unverändert. Bisher wurde es ersetzt und verlor Kalender und Kontakte.
```

**Français**
