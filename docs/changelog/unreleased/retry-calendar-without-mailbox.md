# Retrying a calendar or address book leaves the mailbox alone

Platforms: all
Bump: patch

> A calendar or address book that could not be reached beside a working mailbox was retried by
> connecting the whole account again: a new sign-in to the mailbox, a sync of every folder and new
> push connections, on every refresh. Yahoo answers that many sign-ins by limiting the account. Only
> the calendar and address book are now connected again.

**English**

```
When a calendar or address book could not be reached, trying again no longer signs in to the mailbox again, so a provider such as Yahoo no longer limits the account's sign-ins.
```
