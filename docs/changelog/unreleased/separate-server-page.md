# A calendar on a server of its own is signed in to from the core's form

Platforms: all
Bump: patch

> The form that gives a calendar or address book a sign-in of its own is decided by the core on
> every platform: it is offered under the last use that needs it, the core asks the server whether
> it signs in through a provider or with Nextcloud, and Connect and setup's Skip each show that
> they are working until they end.

**English**

```
The form for a calendar or address book on a server of its own now shows that Connect or Skip is working until it is done, on every platform.
```
