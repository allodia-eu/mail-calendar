# A way back from account setup

Platforms: macos, ios, windows
Bump: patch

> The detected-settings and manual steps of account setup had no way back to the address step on
> Apple or Windows. Android already stepped back with the system Back and Linux with a button.

**English**

```
Account setup now has a Back button that returns from the found settings or the manual form to the email address step.
```
