# The question about a calendar's new server stays open while it connects

Platforms: linux
Bump: patch

> Allowing a calendar or address book server found on another site kept the question open on the
> other platforms already. On Linux the question closed at once and its outcome appeared on the
> account's page or not at all; Allow could also be pressed twice.

**English**

```
When you allow a new calendar or address book server, the question stays open until it has connected, and says so there if it could not.
```

**Nederlands**

```
Als je een nieuwe agenda- of adresboekserver toestaat, blijft de vraag open tot er verbinding is, en staat daar ook als dat niet lukte.
```
