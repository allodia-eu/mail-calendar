# Invitations through a linked calendar

Platforms: all
Bump: minor

> A mailbox linked to a calendar account in Settings now files its invitations into that calendar
> and answers them from it; a reply that has to be emailed goes from the mailbox, also for an
> answer given from the calendar.

**English**

```
An invitation in a mailbox linked to a calendar account is now put on, and answered from, that calendar, with any reply emailed from the mailbox.
```

**Nederlands**

```
Een uitnodiging in een mailbox die aan een agenda-account is gekoppeld, komt nu in die agenda en wordt daarvandaan beantwoord; een antwoord per e-mail gaat vanuit de mailbox.
```

**Deutsch**

```
Eine Einladung in einem Postfach, das mit einem Kalenderkonto verknüpft ist, wird jetzt in diesen Kalender eingetragen und von dort beantwortet; eine Antwort per E-Mail geht vom Postfach aus.
```

**Français**

```
Une invitation reçue dans une boîte liée à un compte d’agenda est désormais ajoutée à cet agenda et y reçoit sa réponse ; une réponse par e-mail part de la boîte.
```

**Español**

```
Una invitación en un buzón vinculado a una cuenta de calendario ahora se añade a ese calendario y se responde desde él; la respuesta por correo sale del buzón.
```

**Italiano**

```
Un invito in una casella collegata a un account di calendario ora viene aggiunto a quel calendario e risposto da lì; la risposta per e-mail parte dalla casella.
```

**Português**

```
Um convite numa caixa de correio ligada a uma conta de calendário passa a ser adicionado a esse calendário e respondido a partir dele; a resposta por e-mail sai da caixa de correio.
```
