# The calendar card the link step opens says what it adds

Platforms: android, linux
Bump: patch

> The card opened for the calendar or address book found beside a JMAP server says it adds to the
> mail account instead of "no mail server", and every calendar-only card mentions app passwords.

**English**

```
Setting up the calendar found beside your mail account now says it adds to that account, and mentions that some servers need an app password.
```

```

```
