# Sign in to a calendar server of its own

Platforms: all
Bump: minor

> A calendar and address book on a server the mailbox's sign-in does not reach could be set up
> only with a password. Where that server signs in through a provider of its own, setup and the
> account's page now offer that sign-in.

**English**

```
A calendar on a separate server can now sign in through that server's own provider, where it offers one, instead of a password.
```

**Nederlands**

```
Een agenda op een aparte server kan nu aanmelden via de eigen provider van die server, als die dat aanbiedt, in plaats van met een wachtwoord.
```

**Deutsch**

```
Ein Kalender auf einem eigenen Server kann sich jetzt über den Anbieter dieses Servers anmelden, sofern er das anbietet, statt mit einem Passwort.
```

**Français**

```
Un calendrier sur un serveur distinct peut désormais se connecter via le fournisseur de ce serveur, s’il le propose, plutôt qu’avec un mot de passe.
```

**Español**

```
Un calendario en un servidor aparte ya puede iniciar sesión con el proveedor de ese servidor, si lo ofrece, en lugar de con una contraseña.
```

**Italiano**
