# Add an account from Settings on a Mac, iPhone and iPad

Platforms: macos, ios
Bump: patch

> The folder pane's "Add account…" row is gone; Settings → Accounts opens with the button
> (`docs/settings.md` row 9).

**English**

```
Another account is now added from Settings → Accounts, where Add account sits above the accounts already set up, rather than from the bottom of the folder list.
```

**Nederlands**

```
Een extra account voeg je nu toe via Instellingen → Accounts, waar Account toevoegen boven de accounts staat die al zijn ingesteld, in plaats van onderaan de mappenlijst.
```

**Deutsch**

```
Ein weiteres Konto fügen Sie jetzt unter Einstellungen → Konten hinzu, wo „Konto hinzufügen“ über den bereits eingerichteten Konten steht, statt am Ende der Ordnerliste.
```

**Français**

```
Un autre compte s'ajoute désormais depuis Réglages → Comptes, où Ajouter un compte figure au-dessus des comptes déjà configurés, et non plus en bas de la liste des dossiers.
```

**Español**

```
Otra cuenta se añade ahora desde Ajustes → Cuentas, donde Añadir cuenta aparece encima de las cuentas ya configuradas, en lugar de al final de la lista de carpetas.
```

**Italiano**

```
Un altro account ora si aggiunge da Impostazioni → Account, dove Aggiungi account si trova sopra gli account già configurati, anziché in fondo all'elenco delle cartelle.
```

**Português**

```
Outra conta adiciona-se agora em Definições → Contas, onde Adicionar conta aparece acima das contas já configuradas, em vez de no fim da lista de pastas.
```
