# No web inspector on Windows

Platforms: windows
Bump: patch

> A release build opened the WebView2 developer tools on F12 in the message and composer views,
> and obeyed the WebView2 environment variables, one of which opens a remote-debugging port on
> every page. Neither reaches a release build now (rendering-security.md, gate 2a).

```
Messages and drafts can no longer be opened in the browser's developer tools, by you or by another program on the computer.
```
