# Allodia Mail & Calendar 0.20.0

Released 27 November 2026.

This release brings a clearer open message on phones, writing in a dark app, and a long list of fixes! 🚀

- **An open message on phones**: on iPhone, iPad and Android an open message keeps the Mail, Calendar and Contacts tabs and shows its full subject and its recipients by name, with every address a tap away, and unread mail is marked with a dot in the list. On iPhone and iPad the actions sit in the top bar; on Android the conversation scrolls as one page, with large Reply and Forward buttons at the bottom of the screen.
- **Writing in a dark app**: a message you write looks as it will when read, and the sun or moon on the formatting bar switches between dark and light. Available on every app.
- **Save all attachments**: Save all saves every attachment of a message at once, into a folder you choose. Available on every app.
- **Calendar and contacts servers**: an account's settings take a calendar or address book server of its own, on every app, and the manual setup adds a Nextcloud calendar and contacts from the server's address alone, on macOS, iPhone & iPad, Windows and Linux.
- **Drag on the Windows calendar**: drag across empty time to create an event, or drag your own events to move or resize them.

**The latest version is available through our website: [https://allodia.eu/mail-calendar](https://allodia.eu/mail-calendar)**

**Store availability**: ⏳ this version is in review in the stores; this line changes to ✅ once it is live on all supported platforms.

The changes below are grouped by where they landed. The first section reached **every app**. The sections after it cover changes that did not reach all of them, so a change that landed on two apps is listed under both.

## 🌟 Every app: macOS, iPhone & iPad, Windows, Android and Linux

### ✨ New

- **A message is written on the page it will be read on.** In a dark app, a message you write now looks as it will when read, and the sun or moon on the formatting bar switches between dark and light.
- **Save all attachments at once.** Save every attachment of a message at once with Save all, into a folder you choose.

### 🔧 Fixed

- **A calendar that leads past the provider's sign-in says so.** When a calendar or address book server sends the app on to a server your provider's sign-in does not cover, the account now says that this use needs a sign-in of its own, rather than that the server has nothing for the account.
- **A new-mail notification shows the start of the message as one run of text.** A new-mail notification shows the start of the message without empty lines.
- **A reply to a plain-text message carries clean line endings.** Replies to plain-text messages no longer end the quoted text with a stray line-ending character.
- **A server at a plaintext address is no longer sent a sign-in.** A calendar, address book or JMAP mail server at an http:// address that is not on this device, or one that sends the app on to such an address, is no longer sent your sign-in, and the app says what clears it.
- **A stored sign-in the server could never accept asks to be updated.** A stored password or token that the server could never accept, such as an API token containing a space, now asks you to update it, instead of showing the server as unreachable.
- **Address book server in an account's settings.** An account's settings now let you enter a separate address book server when its contacts are not on the calendar server.
- **An account signed in through its provider keeps its calendar and contacts.** The calendar and contacts of an account you signed in to through your provider, other than a Google or Microsoft account, keep working past the first hour, and for every account signed in this way a sign-in the server stops accepting early is renewed without asking you to sign in again.
- **Answering an invitation to a meeting far ahead works on a CalDAV calendar.** Answering an invitation to a meeting further ahead than the calendar had loaded no longer fails or sends the reply without recording your answer, and a meeting with a very long ID can now be added to the calendar.
- **Calendar server for a mailbox in an account's settings.** A mail account that signs in with a password can now be given a calendar or address book server in its settings.
- **Enter in the signature's first line starts a line of the message.** Pressing Enter at the start of your signature now adds a line to your message, and lines typed there are sent as you see them.
- **Folders show before their mail has downloaded.** A newly added account or shared mailbox shows its folders straight away, while its mail is still downloading.
- **The composer spaces a message as it is sent.** The composer now shows your message spaced exactly as it is sent, with a blank line above your signature.
- **The usage statistics preview shows every kind of event.** “See exactly what we send” now shows every kind of usage statistic the app can send, not only the launch.

### ✨ New
