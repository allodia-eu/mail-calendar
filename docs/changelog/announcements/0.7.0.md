# MailCal 0.7.0

Released 31 August 2026.

This release is about one thing: there is now a Linux app. It is the fifth client, it is built from the same core as the others, and it arrives with the mail and calendar work already done rather than as a preview. Nothing changed for macOS, iOS, Windows or Android.

---

## 🐧 Linux (not yet in a store)

- **Allodia Mail & Calendar on Linux.** Allodia Mail & Calendar now runs on Linux, installed as a Flatpak, with your mail and calendar accounts, a unified inbox, threaded reading, the rich composer, search and signatures.

The Linux app is not in a store yet, so there is nowhere to update from. The above is what landed this cycle.
