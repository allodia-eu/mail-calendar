## Changes in this release

Engineering commentary, carried over from each fragment. Never pasted into a store.

### The Linux app is packaged again — `the-linux-flatpak-is-built-again` (linux, patch)

> Two faults in the Linux release path, each hidden behind the one before it, and both reachable
> only from a tag: the per-push legs never run either step. `ComposeKind` reached the shell module
> only for the debug-only showcase hooks, so a release build, which compiles those out, met an
> unused import and the denied `unused_imports` lint stopped the compile. Past that, `build-bundle`
> takes the branch as an argument and falls back to `master`, while the manifest publishes to
> `stable`, so it asked the repo for a ref the build had never written. The bundle step now reads
> the branch from the manifest the build actually used and refuses rather than guesses when one is
> absent, which is what keeps the two from drifting apart again.
