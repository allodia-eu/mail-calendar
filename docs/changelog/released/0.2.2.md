## Changes in this release

Engineering commentary, carried over from each fragment. Never pasted into a store.

### Dutch dates on Mac, iPhone and iPad — `apple-dates-follow-the-app-language` (macos, ios, windows, android, patch)

> **Scoped to the Apple platforms on purpose** (rule 4). Windows and Android already formatted dates
> in the app's language; this release brings macOS/iOS/iPadOS in line. One body still goes to all
> three stores, so the note names the platforms rather than claiming a change everywhere.
