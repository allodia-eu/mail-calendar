# 0.2.1 — 2026-07-21

## macos, ios, windows, android

Paste into: Microsoft Store · App Store Connect (macOS) · App Store Connect (iOS/iPadOS) · Google Play

**English**

```
Easier sign-in for JMAP accounts, such as Fastmail.

Where your provider supports it, you can now sign in through your browser — no API token to create. Where it doesn't, connecting takes a single field: your password or an API token, whichever you were given. Before there were two, and choosing the wrong one failed without saying why.
```
