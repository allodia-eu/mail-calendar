## Changes in this release

Engineering commentary, carried over from each fragment. Never pasted into a store.

### Allodia Mail & Calendar on Linux — `linux-client` (linux, minor)

> The Linux client ships from this release, as a Flatpak on the GNOME runtime. What it claims here
> is held to the capability matrix and no further: the four rows still marked ⬜ for Linux there
> (configurable swipe actions, and the calendar's pinch-to-zoom, continuous day strip and wheel
> scrolling) are deliberately absent from the note.
>
> It reaches no store yet, so this note is written down and shipped like any other and simply has no
> console to be rejected by. It is still carried in every catalog locale, because a fragment that
> skipped one would be the first to teach the next author that skipping one is allowed.
